# Posters, Covers, And Key Art

Use this reference for poster prompts, cover images, campaign key art, editorial covers, social thumbnails, title-safe hero images, and promotional stills.

## Core Controls

- Use case: poster, cover, key art, thumbnail, editorial cover, event art, campaign visual, album-style cover, or book-style cover.
- Visual hierarchy: main subject, secondary subject, background, symbolic object, title/headline zone, supporting copy zone, logo-safe area if authorized, and negative space.
- Composition: aspect ratio, crop, subject scale, center or asymmetrical layout, depth, silhouette, border/margins, and safe zones.
- Message: mood, genre, promise, metaphor, product/category, or event subject without copying existing IP or brands.
- Color and light: palette, contrast, key color accent, value grouping, lighting direction, atmospheric depth, and print/digital readability.
- Typography plan: no generated text, blank title area, controlled typography, or exact headline only when the user requests it.

## Text Strategy

Use headline, title, date, subtitle, issue label, or short callout only when requested and supplied. Keep controlled typography short, large, high-contrast, and placed in reserved safe areas. When exact text reliability matters, ask for blank title boxes or clean negative space for post-production text.

Avoid random copy, fake awards, fake endorsements, fake ratings, fake legal lines, random logos, unauthorized brand marks, dense paragraphs, and tiny credits unless the user explicitly needs a credits-style layout.

## Prompt Skeletons

```text
{poster/key art/cover}: {main subject} for {use case}, strong visual hierarchy, {composition/aspect ratio}, clear headline or title-safe zone, supporting negative space, symbolic background or environment, controlled lighting/color palette, print-readable contrast, typography plan: {blank area / supplied headline / controlled title}, no random text or unauthorized logos.
```

```text
{text-free key art}: {subject and metaphor}, poster-like composition, dramatic focal hierarchy, clean negative space for later typography, no visible letters, numbers, captions, watermarks, logos, signage, or typography-like marks.
```

```text
Preserve:
<subject identity, product shape, layout, color palette, supplied headline/logo if authorized>

Edit:
<background, hierarchy, title-safe area, crop, color grade, subject scale>

Avoid:
<random text, fake brands, fake awards, unreadable title, cluttered hierarchy, subject hidden by typography>
```
