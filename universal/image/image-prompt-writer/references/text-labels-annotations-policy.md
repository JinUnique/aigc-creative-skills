# Text, Labels, And Annotations Policy

Visible text is not automatically good or bad. Treat visible text as a design element with a job, location, size, contrast, and reliability plan.

## Use Visible Text When It Adds Production Value

Include controlled text for labels, callouts, panel numbers, legends, chart axes, UI copy, diagram annotations, diegetic prop text, poster headlines, cover titles, signs requested by the user, note bands, scale bars, swatches, section headers, and numbered markers.

Good text instructions are short, large, high-contrast, placed in margins or reserved areas, and limited to the exact words or categories needed. Use readable text only when the image task benefits from it.

## Avoid Text When It Adds Noise Or Risk

Avoid random filler text, gibberish, lorem ipsum, tiny captions, dense paragraphs, accidental watermarks, random brands/logos, unauthorized signage, fake legal/medical/financial details, fake endorsements, fake certificates, and exact typography promises the target platform cannot support.

When exact text reliability matters, use blank label boxes, numbered markers, note bands without generated wording, or external metadata that maps marker numbers to text.

## Placement Rules

- Put professional sheet labels in margins, note bands, callout boxes, swatches, legends, headers, or separate label columns.
- Do not place labels over faces, hands, props, silhouettes, product edges, key environment shapes, or action contact points.
- Use arrows and symbols only when they clarify a callout or flow; keep them away from critical details.
- Keep panel numbers and storyboard labels outside the drawing area when possible.
- Reserve clean negative space for later typography when the user plans to add final text outside generation.

## UI And Information Design

Use placeholder UI when the user asks for a general mockup without specific copy: readable hierarchy, tabs, buttons, cards, charts, icon areas, and neutral blocks, with no random filler text.

Use short readable UI text when the user requests information design, actual UI copy, dashboards, forms, app screens, charts, menus, or diagrams. Keep labels compact: navigation names, field labels, chart axes, legends, status chips, button text, section headers, and one-line callouts.

## Text-Free Branch

For an explicitly text-free image, say so directly: no visible lettering, numbers, labels, captions, signatures, watermarks, logos, UI text, signage, or typography-like marks. Use visual composition, icons without letters, color coding, or object arrangement instead.

## No Blanket Ban

Use no blanket bans on letters, numbers, arrows, symbols, labels, legends, callouts, or annotations. Decide from the user's goal: readable text, placeholder text structure, external metadata, or explicitly text-free image.
