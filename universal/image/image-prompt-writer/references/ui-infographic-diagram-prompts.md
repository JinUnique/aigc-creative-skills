# UI, Infographic, And Diagram Prompts

Use this reference for UI mockups, dashboards, app screens, landing-page screenshots, infographics, charts, process diagrams, maps, explainer panels, system diagrams, and annotated information design.

## Branching Rule

Use placeholder UI when the user asks for a visual mockup but does not provide copy or data. Show structure, hierarchy, controls, cards, charts, menus, icons, and neutral blocks with no random filler text.

Use short readable UI text when the user requests information design, actual UI copy, dashboard labels, app navigation, chart axes, legends, diagram annotations, form fields, buttons, status labels, or callouts. Keep text compact and high-contrast.

## UI Controls

- Surface: app screen, dashboard, mobile UI, web page, kiosk, control panel, settings page, editor, or data product.
- Layout: nav, sidebar, toolbar, cards, table, chart, form, tabs, modal, timeline, map, canvas, or split view.
- Text: short navigation names, button labels, field labels, status chips, section headers, tooltip-like callouts, or placeholder blocks.
- Visual hierarchy: primary task, selected state, grouped controls, data density, spacing, alignment, and readable labels.
- Constraints: no random filler text, no fake brands, no illegible microcopy, no impossible charts, no overlapping UI.

## Infographic And Diagram Controls

- Diagram type: flowchart, explainer, technical diagram, anatomy chart, map, timeline, comparison table, process diagram, or data visualization.
- Information objects: title/header if requested, numbered steps, arrows, icons, chart axes, legends, color keys, annotation labels, callout boxes, scale bars, and captions.
- Reliability: keep text short; for exact content use numbered markers plus external metadata or blank label boxes.
- Placement: labels and callouts outside key subject shapes, connected by clean leaders or arrows.

## Prompt Skeletons

```text
{placeholder UI mockup}: {screen type} for {use case}, clear layout with navigation, controls, cards, charts, tables, forms, and icons as needed, realistic hierarchy and spacing, neutral placeholder blocks instead of readable filler copy, no random text, no fake brands, no overlapping elements.
```

```text
{readable UI screen}: {screen type} with short readable UI text: navigation {items}, buttons {labels}, fields {labels}, chart axes {axis labels}, legends {legend names}, status labels {labels}; clean hierarchy, high contrast, realistic spacing, no long prose or random copy.
```

```text
{infographic/diagram}: {topic}, structured information design with numbered markers, chart axes, legends, diagram annotations, callout boxes, arrows, color key, and optional title, labels placed outside core shapes, short high-contrast text, no gibberish or dense paragraphs.
```
