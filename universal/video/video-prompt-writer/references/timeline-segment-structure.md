# 时间轴与镜内节拍

本文件处理单个 Prompt Payload 内部的事件时间。跨生成单元的容量、分段与交接由 [容量与分段](story-capacity-and-prompt-pack.md) 负责。

## 何时需要时间轴

- 用户或下游要求精确时间、固定镜头表或音画同步时，提供对应节点。
- 完整故事、多阶段行动或多镜头使用结构化时间轴。先按真实完成时间安排先后与并行关系；目标时长已确定且入口支持时标本地范围，否则用明确阶段表达，不伪造精确控制能力。
- 单镜头且无复杂时序/同步关系的简单观察、动作或气氛片段，以及局部编辑，可直接用自然段；多阶段或多镜头按结构化默认，用户指定格式优先。
- 连续 pack 的每段内部都核对本地时间；若正文含时间码，从该段 0 开始。入口不支持数值时间控制时，以阶段表达事件，外部清单保留计划时间，并说明控制限制。

## 切分原则

按主要行动阶段、信息显露、空间关系、摄影机行为、声音节点或状态变化切分。同一过程需要更多完成时间就给更长片段，不机械均分、不凑镜头数。

连续长镜头可以通过移动、遮挡、移焦、构图、光线或声音变化组织多个节拍，也可以持续观察同一状态。时间片标明镜头归属，边界区分镜内延续与切镜；稳定镜头不必添加人物动作或剧情转折。同一镜头的持续构图与运动可沿用其已定义基线，只展开本阶段变化。

以下仅作起始观察，不是容量承诺或数量门槛：

| 时长 | 常见承载 |
|---|---|
| 1–2 秒 | 一个可辨识动作点、反应或状态 |
| 3–8 秒 | 一个核心变化或连续观察，常见 1–3 个节拍 |
| 9–15 秒 | 一组相关变化，常见 2–4 个节拍 |
| 16–30 秒 | 一个完整单元或持续长镜头，常见 4–7 个节拍 |

更多时长是否可原生执行取决于平台。已有动作、台词、节奏或形式优先于这些经验范围。

## 时间核对

1. 主视觉时间片从 0 开始，到目标时长结束；相邻主片段连续、不倒序、不意外重叠或留空。
2. 同一时间可有并行的动作和声音轨；把它们放到同一个主时间轴中，不按多轨时长相加。
3. 每个关键动作、阅读、反应和接触结果有实际位置与完成时间。总量能装下也要检查局部顺序能否成立。
4. 片尾保留用户需要的稳定画面、反应、声音收尾或续接状态。具体余量由内容决定，不机械扣除固定比例。
5. 正文时间码遵从 [目标入口](generation-modes-and-platforms.md) 的支持精度。内部更精细的估算不自动成为平台支持的小数秒指令。

容量不足时回到主 skill 的意图路由：保留锁定内容，严格单片不能擅自分段或加速；完整故事按安全接点编译 pack。

## 视听职责

- 自然变化可直接写入动作句。适用效果在 VFX 字段展开；默认结构中无人工视效时简短注明，不用自然现象填满字段。
- 声音基线只写一次；具体事件音、人声、声桥和变化才标节点。默认结构中的局部声音字段可以沿用全局方案；纯静音不需要每片重新设计声层。
- 各字段用共同事件节点表达先后、并行或有意错开的声画关系，字段排列不代表事件排列。状态与衔接补充需要保持或传递的结果，不强制情绪变化，也不重复整段动作。
- 外部音乐、生成拟音和原声保留可按声层分工，详见 [声音设计](sound-design-foley-ambient-mix.md)。没有实测 cue、BPM 或拍点时不编造精确同步。
- 对白的实测、重叠区间并集、禁占时间与可懂度只按 [对白计时](dialogue-pace-and-voiceover.md) 计算。人声可有意跨镜延续，不要求每句在镜头切换前收完；生成段末则必须能完整交付或有已确认的音频续接方式。

## 渲染

按 [表达结构](prompt-structure-framework.md) 的优先级与字段职责输出。默认结构保留七个时间片标签；自然阶段可以填在时间段字段中，不取消其余结构。简单观察、局部编辑与用户/下游指定格式按该参考处理。内部审计与能力说明留在代码块外。
