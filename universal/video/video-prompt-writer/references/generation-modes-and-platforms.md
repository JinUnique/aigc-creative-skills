# 生成模式、素材职责与平台能力

先分清任务，再选择当前入口支持的实现。提示词能描述某种结果，不等于当前模型、产品页面或 API 已开放该操作。

## 任务与素材分开判断

| 主任务 | 提示词重点 | 保留边界 |
|---|---|---|
| 生成 | 主体、核心变化、影像意图与必要声音 | 用户事实和参考负责的属性 |
| 编辑 | 原视频、修改对象、时间/区域范围、目标变化 | 未指定修改的身份、动作、相机、时长、声音等 |
| 延长 | 前置/后续方向、相应边界状态、新增内容与新增时长 | 原片内容及边界处的身份、空间、动作、道具、光线与音频连续性 |

图像、视频、声音、首尾帧和布局参考是叠加的控制来源，不必把它们当互斥创作流程。“融合”需要落实为当前工具支持的参考生成或编辑操作，不能凭名称宣称存在独立接口。

## 素材绑定

内部按实际需要记录 `素材标识 → 职责 → 锁定属性 → 可变属性`。一份素材可以控制多个兼容属性，多份素材冲突时逐属性确定优先级；不让动作参考顺带替换用户锁定的外观。

- **外观/身份参考**：引用其身份、服饰或材质；补充本次动作和未覆盖环境，不重写所有可见细节。
- **动作/运镜参考**：说明参考哪一段运动以及需要迁移的部分；素材已清楚呈现的全过程无需逐帧复述。动作和运镜不是人物身份授权。
- **布局/白模参考**：负责空间、比例和运动路径时，外观、材质和最终质感可由其他输入决定。
- **声音参考**：区分音色身份、台词内容、配乐、节奏与原声保留。参考声音不能凭文本保证已克隆音色或锁定波形。
- **首尾帧**：区分原生参数绑定与文本中的语义要求。实际提交为 `first_frame` / `last_frame` 的素材才能称为该接口的首尾帧绑定；仅把 `reference_image` 在文本中称为“首帧”，不保证相同约束或画幅行为。

用户未指定实际 `@素材名` 时，不制造已上传句柄。无法查看素材时只使用用户声明的职责，不编造画面细节；缺失细节确实决定修改范围或连续性时再询问。

## 任务写法

**生成**：从参考未解决的目标开始写。单一观察可保留稳定画面与细微变化；多事件使用阶段或镜头组织。

**编辑**：优先写“对谁、改什么、在哪段时间/区域、其余保留”。原片机位、声音、字幕等若属于保留项，不能被通用默认禁令覆盖。要求整片只改一处时，不新增全片分镜、人物表演和光线方案。

**延长**：先识别前置或后续方向，并区分“新增时长”与“延长后的总时长”。后续延长从原片尾部状态开始；前置延长以原片首部状态结束，避免提前出现只属于原片后续的状态。读取对应边界证据，缺证据时给条件式方案；方向不明且会改变交付时澄清。前置与后续能力分别核对，支持一种不意味着支持另一种。保留原片，不在边界重放已完成动作；声音续接按实际工具和输入承载设计，不用“无缝”代替状态。

## 能力资料

需要声称可以执行时，核对与本次任务相关的能力：

```text
platform / model_version / entrypoint
verified_at / source
supported_operations
min_duration / max_duration / allowed_durations
reference_types / reference_roles / reference_limits
audio_generation_or_preservation
timestamp_support / prompt_limit
```

这些是核对维度，不要求缺一项就阻塞所有写作；只把与本次执行相关且已知的值纳入判断。来源可为当前官方资料、实际入口或调用方明确提供的能力，注明其依据。产品发布、网页功能与 API 支持不能相互推定；旧模型资料不能直接套到新模型。

- `native`：当前任务和具体时长可直接提交。
- `extend`：当前入口确认支持延长，并有可继承输入。
- `segment`：用户、内容容量或已知工具链要求多个生成单元；每段仍须符合实际提交约束。
- `confirmed`：本次执行相关条件已确认；`conditional`：有待核对的具体条件；`blocked`：已有明确限制与要求冲突。

例如平台只支持 5 秒和 10 秒，即使某段 7 秒低于最大值，也不能判定可以原生提交。先在用户意图内寻找支持档位的分段与时间安排；需要改动锁定时长或事件时说明冲突。未知能力无需猜测数值，可先写用户需要的提示词并保留执行条件。

## 时间表达

提示词内的事件时间与生成接口的 duration 参数分别处理。简单短片可用自然顺序；需要指定节点时使用目标入口支持的时间码。内部可以细分事件估时，正文不因此自动输出大量小数秒指令。

当字幕、镜头或事件时间已由用户锁定，保留其意图与顺序；入口无法表达所需精度时说明限制，不能静默改成另一节奏。
