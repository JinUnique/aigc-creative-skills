# 镜头语言决策库

本文件用于把已经完成的 `DirectorialPlan` 翻译成景别、视点、构图、焦距效果、摄影机行为和剪点。它不是同义镜头菜单，也不负责从运镜词反推故事。导演策略、blocking、轴线、声音桥和最后一帧的完整规划见 `cinematography-storyboard-production-design.md`。

只提供通用术语、选择条件、可见效果与检查问题；不提供固定题材、固定场景、固定人物、固定镜头套装或按导演姓名调用的风格 preset。

---

## 一、选镜前置条件

在选择任何镜头术语前，当前 beat 至少已有：

```text
viewer_knows: <观众此刻知道什么>
viewer_feels: <由哪些可见 / 可听证据产生>
viewer_waits_for: <观众在等什么>
subject_objective: <人物试图改变谁或什么>
blocking: <位置、距离、朝向、视线、路径、遮挡与结束几何>
reveal: <本 beat 新增、隐藏或重解释什么>
camera_motivation: <为什么此刻移动 / 停下 / 切换 / 重构>
sound_bridge?: <若声音跨点承担信息、POV、连续性或余波，引用 canonical SoundBridge>
transition?: <仅非末 beat 且确需显式衔接时，写如何进入下一 beat>
```

核心叙事项答不清，先回导演层，不要用景别、焦段或复合运镜补空白。`sound_bridge?` 与非末 beat 的 `transition?` 是条件槽位，缺失不推翻 beat；beat 只按其戏剧增量成立。“电影感”“高级感”“镜头丰富”“更酷”都不是有效前置条件。

## 二、ShotDecision 内部槽位

```text
ShotDecision
  beat_id: <对应 DirectorialPlan beat>
  narrative_gain: <新增信息 / 关系变化 / POV 变化 / 情绪重置>
  attention_start: <观众先看哪里>
  attention_end: <观众最终看哪里>
  subject_and_blocking: <主体位置、距离、朝向、视线、路径、遮挡>
  shot_scale: <景别及必须看清的内容>
  viewpoint: <客观 / 主观 / 过肩 / 反应 / 其他有功能视点>
  camera_side_and_axis: <机位相对视线轴 / 动作轴的位置>
  lens_and_depth_effect: <透视、压缩、景深的可见效果>
  composition: <主体比例、前中后景、留白、边界、焦点优先级>
  camera_behavior: <移动 / 静止 / 切换 / 镜内重构>
  trigger: <启动、停止、切换或重构的动作 / 信息 / 声音 / 情绪节点>
  stop_or_cut_point: <停点或剪点及其结果>
  continuity: <屏幕方向、进入离开、视线、物件、光线；若存在则包含 sound_bridge?>
  visible_function: <术语在最终画面产生什么可观察效果>
```

最终提示词不必输出内部槽位名，但应在对应主模板字段中写清关键决定。

## 三、选镜顺序

1. **写叙事增量**：这一镜或这次重构带来哪项新信息、关系变化、POV 变化或情绪重置？
2. **写注意力路径**：观众从哪个主体、动作、声源、物件或空间层转到哪里？
3. **核 blocking**：主体的相对位置、移动方向、视线和遮挡是否已经可读？
4. **定必须看清的尺度**：空间、全身路径、交互、反应还是微小信息决定景别。
5. **定观众位置**：观众是旁观、与某角色共享感知，还是先读反应后读原因？
6. **定轴线侧与连续性**：保持或有意改写视线轴、动作轴和屏幕方向。
7. **定相机行为**：只选一个主行为；其他变化只有承担独立功能时保留。
8. **绑定触发与停点**：为什么此刻开始，何时因为信息 / 关系结果而停下或切走？
9. **绑定生产效果**：焦距、景深、构图、光线和声音桥只保留必要控制面。
10. **删除测试**：删除一个术语后若可见结果和叙事功能不变，该术语是装饰。

## 四、景别：按必须看清的信息选择

| 必须看清的内容 | 景别选择倾向 | 可见效果与风险 |
|---|---|---|
| 环境尺度、路径、边界、群体或主体与世界比例 | 大远景 / 远景 | 地理关系清楚；人物微表演弱，不能同时要求细小表情 |
| 完整身体、走位、高低差、接触前后的动作链 | 全景 | blocking 和路径可复原；脸部细节有限 |
| 双方关系、上半身动作、物件交换、对白策略 | 中景 | 兼顾表演与空间；背景需简化到不抢主动作 |
| 反应、呼吸、视线、声线变化、局部动作 | 近景 | 情绪距离变近；地理关系需由前镜或构图锚点维持 |
| 决定理解的单一信息、触点、眼神或物件状态 | 特写 | 注意力高度集中；只有产生新信息时使用 |
| 高潮中的极小变化且其他信息应暂时消失 | 大特写 | 强制注意；频繁使用会失去尺度和效果 |

规则：

- 景别变化必须对应信息密度、关系距离或情绪距离变化，不能机械“远 → 中 → 近”。
- 近景 / 特写不是情绪的默认答案。若权力来自空间控制，保留能读到 blocking 的景别。
- 宽景别不等于建立镜头；只有建立了行动路线、边界或关系才算完成建立。
- 同一 beat 只选能看清主变化的最简尺度，不同时要求“全空间 + 微表情 + 微小触点”全部同等清楚。

## 五、视点：决定观众与谁一起知道

### 5.1 客观视点

用于让观众读取空间事实、多人关系和完整行动因果。客观不等于无立场；机位距离、遮挡和信息顺序仍决定观众偏向。

### 5.2 受限主观 / POV

用于让观众共享某角色能看、听、误判或暂时无法确认的范围。必须写清：

```text
pov_owner → perceptual_limit → attention_target → revealed_or_misread_information → exit_from_pov
```

主观性不能只靠模糊、抖动、滤镜或失真词；需要视线、声音、反应和信息边界共同成立。

### 5.3 过肩

前景肩背或身体边界用于说明观察位置、距离、遮挡或权力，不是对白默认格式。前景所占比例、远处焦点和 eyeline 必须清楚。

### 5.4 正反打

每次反打至少对应一项变化：新 tactic、新信息、权力转移、未说出口的反应或情绪重置。若只是把同一句信息从两侧重复，保留更有增量的一侧。

### 5.5 反应视点

可先给反应制造对原因的等待，也可在事件后把后果交给被影响主体。反应必须增加人物判断或关系信息，不是纯粹“惊讶特写”。

### 5.6 空间 / 环境视点

只有空间状态、痕迹、声源或环境运动承担信息、阻力、后果或转场时使用。没有功能的空镜不作为“氛围镜头”自动添加。

## 六、构图、遮挡与景深：组织信息，不装饰画面

### 6.1 构图按关系选择

- 中心 / 对称：当稳定规则、控制、被观看或即将被打破的秩序需要可见。
- 边缘 / 不对称：当退出、排斥、未占据空间或关系失衡需要可见。
- 留白：当观众等待某物进入、主体无法跨越、未知或关系距离需要空间承载。
- 框架边界：当空间权限、观察位置、分隔或受限感需要可见。
- 对角 / 引导关系：当动作方向、阻力或注意力路径必须被读到。
- 多层纵深：当前景观察 / 遮挡、中景行动、背景线索同时参与同一戏剧问题。

不要把多个近义构图标签叠在一句中。选择能最直接表达 blocking 与信息关系的一项，并写可见结果。

### 6.2 遮挡

```text
occluder → hidden_subject_or_information → duration → reveal_trigger → interpretation_change
```

遮挡必须延迟、误导、建立观察位置或表达边界。若遮住动作接触点、表演证据或地理锚点且无意图，应移除。

### 6.3 景深

- 浅景深：隔离当前信息；焦点从 A 到 B 的变化必须由视线、声源、动作或揭示触发。
- 深焦：并置多个深度层的选择、信息差、动作因果或权力关系。
- 焦点外信息：只在观众应察觉但暂不能确认时使用，并设计何时进入清晰区。

“浅景深、深焦同时突出全部主体”属于冲突指令，必须按主信息选择。

## 七、焦距效果：写空间心理，不堆毫米数

| 焦距效果 | 可观察结果 | 适用功能 | 主要风险 |
|---|---|---|---|
| 广角贴近 / 自然广角 | 近远差扩大，人物与环境、行动路径同时可读 | 临场、空间压力、连续走位、环境参与 | 近距离面部和边缘形变 |
| 标准视角 | 透视自然，表演与空间保持中性平衡 | 关系观察、对白、精确行为 | 若 blocking 弱，画面容易仅像记录 |
| 中长焦压缩 | 前后距离看似收紧，背景更集中，主体更孤立 | 反应、观察、受限空间感、关系压缩 | 地理与动作路径变弱 |
| 长焦远观 | 观察距离增强，空间层被压平 | 被观察、不可接近、等待或隔离 | 跟随与接触可读性下降 |
| 微距 / 极近光学 | 材质、触点和小尺度状态成为主信息 | 决定理解的细节或因果节点 | 容易失去主体与空间归属 |

提示词优先写“焦距效果 + 可见结果 + 叙事功能”，只有平台或生产需要时再写具体毫米数。

**具体毫米数的书写格式**：当真需要写毫米数时，使用阿拉伯数字 + 标准单位（24mm、50mm、85mm），不使用中文数词（不写「二十四毫米」「八十五毫米」）。写法示例：`24mm广角建立空间纵深，85mm近景完成细节揭示`。修辞性或泛指数字（如「千万粒」）不属于精确可量化参数，不强求阿拉伯化。

## 八、摄影机行为：一个主行为，一条因果链

### 8.1 通用表达式

```text
<触发节点>使摄影机<移动 / 停下 / 切换 / 重构>，
注意力从<起点>转到<终点>，
从而<增加信息 / 改变关系 / 转换 POV / 重置情绪>，
并在<动作 / 反应 / 构图 / 声音落点>停住或切出。
```

### 8.2 移动

- **推近 / 靠近**：因为信息、反应或决断需要缩短观众距离；终点是具体面部、手部、物件或关系结果。
- **拉远 / 远离**：因为个人动作需要扩展为环境后果、隔离或新空间关系。
- **摇转**：因为视线、声音或动作把注意力从一个信息点交给另一点；写清起终点。
- **横移 / 升降**：因为空间层级、路径、高低关系或遮挡需被逐步理解；不是展示空间的默认巡游。
- **跟随**：因为人物 / 物件的连续行动本身承载因果；写相对位置、距离、方向和何时停看。
- **环绕**：因为关系轴、包围状态或主客位置需要可见重写；写起止方位与新关系。
- **焦点转移**：因为另一深度层出现新信息、反应或声源；本质是叙事中心转移。

### 8.3 静止

相机静止可以强调等待、规则、精确行为、权力不动或让人物自行改变构图。必须写画面内部变化：呼吸、视线、位置、物件、光线、环境或声音。

### 8.4 镜内重构

通过人物走位、前景显露、焦点改变、相机小幅调整或主体比例变化完成新构图。每次重构都要新增信息、改变关系或重置情绪；无意义走位不是重构。

### 8.5 切镜

切镜的硬门槛：

```text
new_information OR relationship_change OR viewpoint_change OR emotional_reset
```

四项都没有时，不切。剪点应落在动作、反应、视线、遮挡、声音或信息变化上，并说明下一镜为什么从该点开始。

## 九、长镜头与多镜头的选择

### 9.1 选择长镜头

当连续时间、空间因果、表演积累、程序流程或权力移动需要不被剪辑打断时使用。内部节拍可由以下变化组织：

- 人物进入 / 离开或跨越深度层；
- blocking 和权力几何改变；
- 遮挡显露或焦点交接；
- 相机从跟随转为停看，或从观察转为受限主观；
- 声音先入、环境变化或静默接管注意力；
- 构图在动作结果处稳定为最后一帧。

“超过某秒必须重构”不是硬规则；是否重构取决于 beat 是否变化。长镜头无需为了镜头数主动切开。

### 9.2 选择多镜头

当不同视点确实各自贡献不可替代的信息、关系或情绪变化时使用。先列每镜 `narrative_gain`；任何两镜增量相同，合并或删除其中一镜。

- 不做无动机主镜头 + 全套 coverage。
- 不为对白机械正反打；让策略、权力和反应决定何时换侧。
- 不让快切、甩动、环绕、慢动作和复杂视效同时争夺注意力。
- 动作镜头优先保证起点、路径、接触、受力反应和终点，而不是镜头数量。

## 十、轴线与方向快速门槛

每次切换或大幅重构前检查：

```text
eyeline_axis: <主体视线关系>
action_axis: <主要移动 / 接触方向>
camera_side: <当前机位位于轴线哪侧>
screen_direction: <主体左 / 右、靠近 / 远离、前 / 后景运动>
entry_exit: <从何处进入、向何处离开>
geographic_anchor: <观众用何关系定位>
```

默认保持 180 度连续性。越轴仅在空间关系被镜内可见地重写、经过中性定位，或明确需要迷失、主观断裂、权力翻转、节奏重置时发生；同时写 `crossing_trigger`、`orientation_cue` 和 `intended_effect`。

## 十一、声音与剪点

镜头语言必须预留声音承担注意力和连续性的可能：

- 声音先于画面：下一信息的声源先入，观众先等待再看见。
- 余音跨切：动作、语言或环境尾音保留因果与情绪。
- 环境连续：镜头切换但同一空间底层不重启。
- 主观声切换：视点改变时，声音范围、清晰度或遮挡同步变化。
- 静默剪点：明确哪些声层收住、哪些残留，不把静默写成绝对无声。

以下与导演 / 声音文件使用同一个 canonical 最小契约；声音文件只允许追加 `image_relation / mix_path` 等扩展，不能重命名最小字段：

```text
SoundBridge
  function: <确认 / 预告 / 可解释误导 / 主观化 / 连续>
  source: <明确声源>
  point_of_view: <客观空间或所属角色>
  starts: <前一 beat 的节点>
  crosses: <切镜 / 重构 / 动作转折>
  resolves: <后一 beat 何时显露、衰减或被重解释>
  viewer_effect:
    knows: <新增或修正的信息；无则 none>
    feels: <由可听证据造成的感受变化；无则 none>
    waits_for: <等待显露、完成或解释什么；无则 none>
```

`sound_bridge?` 仅在声音确实跨点承担信息、POV、连续性或余波时实例化。若声音已经完成揭示或转场，不必再增加同义镜头运动；详细声源、空间与混音实现见 `sound-design-foley-ambient-mix.md`。

## 十二、术语绑定格式

任何专业术语进入最终提示词前，使用内部格式检查：

```text
canonical_term: <规范术语>
observable_effect: <画面 / 运动 / 空间 / 声音中可观察的结果>
narrative_function: <信息 / 关系 / 行为 / POV / 情绪作用>
trigger_and_limit: <何时启用、何时停止、主要风险>
compatibility: <与其他术语、blocking、参考素材和平台是否冲突>
```

默认每个控制面只选一个主术语；同义词不并列。若模型可能误解，写“术语 + 一句可观察结果”，不要追加更多近义术语。

## 十三、常见失败与修复

- **从运镜词开工**：回到 `viewer_knows / feels / waits_for` 和 subject objective。
- **同义菜单堆叠**：保留一个最能实现 camera motivation 的主行为，删除其余。
- **切镜无增量**：合并镜头或让新视点真正改变信息、关系、POV 或情绪。
- **长镜头被机械切开**：若空间因果和表演积累需要连续，改用镜内 blocking、焦点和声音组织 beat。
- **多镜头无动机覆盖**：逐镜写 `narrative_gain`，重复者删除。
- **遮挡遮住关键动作**：把显露节点提前，或改变机位与 blocking。
- **浅景深、深焦冲突**：按当前主信息选择一种，并说明焦点逻辑。
- **越轴导致方向跳变**：恢复同侧机位，或补可见跨轴 / 中性定位和明确效果。
- **正反打重复**：只在 tactic、信息、权力或反应变化时反打。
- **“电影感”作动机**：改写成可见空间、透视、运动、光线、表演或声音结果。
- **术语删除后无差别**：删除装饰术语，把字数还给主体行动和时序。

## 十四、交付前检查

- 当前镜头是否对应一个明确 DirectorialPlan beat？
- 是否能说清观众从哪里看到哪里，并得到什么新信息、关系、POV 或情绪变化？
- 景别是否由“必须看清什么”决定，而不是机械远中近？
- 视点是否与观众信息位置一致，主观视点是否有 owner 和感知边界？
- blocking、视线、动作轴、屏幕方向、进入离开方向和遮挡是否可复原？
- 相机为何移动、停下、切换或重构，触发点和停点是否明确？
- 每次切镜 / 重构是否增加信息、改变关系或重置情绪？
- 长镜头是否被允许连续发展；多镜头是否没有无动机 coverage？
