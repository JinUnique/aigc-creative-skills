# 声音设计、拟音、环境声、声音桥与混音层级

本文件负责把 `DirectorialPlan` 的观众信息、视点、转场和情绪余波翻译成可执行声音：环境底层、动作 / 事件音、拟音 / 材质音、人声、声音桥、静默与相对混音。台词行动与角色声线见 `narrative-script-performance-direction.md`；台词预算、朗读 / TTS 实测和画外音计时见 `dialogue-pace-and-voiceover.md`。

这里只提供抽象决策规则、中性占位槽和检查问题；不提供固定人物、固定场景、固定剧情、固定台词、固定音乐主题或垂类样本。默认画内声音优先，用户未明确要求时不写 BGM、配乐、主题曲或音乐化烘托。

---

## 一、声音先服务观众体验

声音可建立空间、氛围、人物感受，也可推动信息和节奏。主动选择适合故事的声层；下列问题用于判断其贡献，不要求每个声音逐项回答：

- 观众因此知道什么？
- 观众因此感觉什么，证据来自声源、距离、动态还是缺失？
- 观众因此等待什么进入画面、完成动作或被解释？
- 声音属于客观空间，还是某个角色的受限感知？
- 它在确认画面、提前预告、制造可解释误导、切入主观，还是维持连续？
- 它何时进入、跨过哪个动作 / 重构 / 剪点、何时解决或衰减？

需要具体事件声或同步时，不能仅用“高级声音设计”等空泛标签代替声源和节点；整体音轨的有效情绪与氛围方向可保留。

## 二、按需 SoundPlan

复杂声场才需要展开计划，简单声层直接描述即可。下列维度按任务选择，无人物或戏剧目标时不填写相应字段。

```text
SoundPlan
  audio_policy: <generated_audio | external_track | silent>
  dramatic_question: <声音服务的当前戏剧问题>
  sound_point_of_view: <客观空间或所属角色；何时改变>
  viewer_knows: <声音使观众确认或推断什么>
  viewer_waits_for: <声音使观众等待什么显露 / 完成 / 被重解释>
  baseline_environment: <贯穿片段的空间底层及变化来源>
  foreground_voice: <对白 / 画外音 / 呼吸是否为前景及可懂度要求>
  key_events: <动作节点、声源、材质、方向、峰值与衰减>
  bridges: <跨 beat / 剪点 / 重构的声音桥>
  subjective_shift: <进入 / 离开主观声场的触发和可听结果>
  silence_and_residue: <哪些层收住、哪些保留到反应或结尾>
  final_sound_function: <回答 / 反转 / 固化 / 余波 / 续接锚点>
```

每个时间 beat 保留有助于空间、氛围、人物、行动或节奏的声层，持续稳定的环境也可以有作用。声音层多不等于声音更好；重要信息需要清楚前景，但不据此省掉有贡献的底层与节点声。

### 2.1 AudioPolicy 三态

- `generated_audio`：生成端负责所需声层；共享声音基线写一次，具体事件出现时才写来源和必要节点。
- `external_track`：外部音轨负责全部所需声音时，生成端可静音；需要同步时使用已提供 cue、歌词或实测节点，不杜撰鼓点/BPM。
- `silent`：交付物全程无声，明确一次即可，不添加环境底噪、呼吸或逐片静默解释。

混合来源时按声层记录 `音层 → generated / reference / external / omitted`。外部音乐可以与生成拟音、环境声并存；只有实际工具支持相应控制才声称可执行。已有视频编辑需要保留原声时以参考原声为准，不用默认禁配乐删除原片声音。

## 三、五层声音模型

```text
片段声音
  = 环境底层
  + 动作 / 事件音
  + 拟音 / 材质音
  + 人声 / 画外音
  + 静默 / 余波
```

不是每条提示词都要写满五层。先按 DirectorialPlan 选择当前观众必须听见的层，再删除不改变信息、动作、关系、POV 或余波的装饰声。

### 3.1 环境底层

环境底层建立空间大小、材质、活动、空气与距离，并在同一连续空间中跨镜保持，不逐镜重启。

```text
EnvironmentBed
  source_system: <可见或可推断的持续声源系统>
  spatial_scale: <近 / 远、开 / 闭、纵深、反射或吸收>
  material_response: <硬 / 软、干 / 湿、粗 / 光滑等可听结果>
  density_and_band: <稀薄 / 密集、低频 / 中频 / 高频的相对倾向>
  continuity: <从何时开始，跨哪些 beat，因何变化>
  narrative_function: <空间定位 / 压力 / 信息 / 对比 / 余波>
```

环境变化要有来源，例如空间开合、主体移动、障碍、结构状态或天气 / 介质变化；不以情绪形容词直接改变声场。

### 3.2 动作 / 事件音

事件音绑定具体节点，回答“哪个动作造成什么可听后果”。

```text
EventSound
  source: <主体 / 物件 / 环境结构>
  pre_sound: <动作前的准备、摩擦、张力或接近>
  contact_or_trigger: <接触 / 开合 / 停止 / 释放节点>
  direction_and_distance: <画面与空间中的方位>
  peak: <相对强度和短暂突出方式>
  decay: <回声、震动、颗粒、结构响应或快速吸收>
  consequence: <它触发谁的反应、揭示什么或改变哪个 beat>
```

峰值必须有前后关系，不能全程都“大声”。

### 3.3 拟音 / 材质音

拟音让动作有触感，不把动作名当声音描述。

```text
action
→ contact_point
→ material_state
→ sound_texture
→ spatial_reflection_or_absorption
→ decay_and_residue
```

- 接触瞬态、物件自身共振与房间混响分别判断。硬表面可产生清晰瞬态，但物件可能持续共振，空间也可能延长尾音，不能由“硬/干”直接推断整体衰减快；
- 软、厚表面倾向吸收冲击、声音较钝；
- 湿、黏状态倾向拖拽、粘连或细小撕扯；
- 颗粒状态倾向分散落点与持续细碎声；
- 材质词必须与画面中的接触、变形、摩擦和空间一致。

这些是物理维度，不是可复制场景。使用时只写当前接触点需要的可听结果。

### 3.4 人声 / 画外音

人声包括台词、画外音、呼吸、截断、重叠、发声距离和遮挡。

```text
VoiceLayer
  owner: <明确角色 / 叙述主体 / 声源>
  narrative_space: <场景内 / 主观 / 面向观众的旁白>
  on_or_off_screen: <适用于场景内声源的入画 / 镜外 / 上一镜延续 / 提前入声>
  speech_action: <该声音正在对谁做什么>
  voice_print: <词汇、句长、直接程度、节奏、情绪泄漏>
  distance_and_occlusion: <场景内声音的远近、方向、障碍与反射；旁白按叙述声音设计>
  timing: <起止、停顿、重叠、打断、退出点>
  priority: <必须听清的前景信息或只作为背景压力>
```

多声源重叠时明确哪句必须听清，重要语言获得合适前景。发声区间、重叠占用与非语言时间仅按 `dialogue-pace-and-voiceover.md` 计算。叙事内声音的声源可以在镜头外；面向观众的旁白不自动继承画中空间的遮挡和混响。

### 3.5 静默 / 余波

本节的相对静默指减少层数、压低动态或突出残留声。用户要求纯静音时不使用这些声层，按 `silent` 交付。

```text
SilenceResidue
  trigger: <信息 / 动作 / 关系 / POV 转折>
  removed_layers: <哪些声层收住或退远>
  retained_sources: <呼吸 / 环境底层 / 回声 / 物件尾音 / 结构余振等>
  viewer_effect: <让观众理解、等待或感受什么>
  end_or_bridge: <在何时恢复、显露或延续至结尾 / 下一 beat>
```

需要相对静默时，选择哪些层收住与留下；纯静音不需要额外声音设计。

## 四、声音桥：先选导演功能，再选跨点方式

声音桥不是只为“转场顺滑”。它可组织信息差、视点、注意力、空间连续和情绪余波。

### 4.1 SoundBridge 契约

以下是跨导演、镜头与声音文件唯一的 canonical 最小契约：

```text
SoundBridge
  function: <确认 / 预告 / 可解释误导 / 主观化 / 连续>
  source: <明确声源>
  point_of_view: <客观空间或所属角色>
  starts: <前一 beat 的节点>
  crosses: <切镜 / 重构 / 动作转折>
  resolves: <后一 beat 何时显露、衰减或被重解释>
  viewer_effect:
    knows: <新增或修正的信息；无则 none>
    feels: <由可听证据造成的感受变化；无则 none>
    waits_for: <等待显露、完成或解释什么；无则 none>
```

需要更细执行时可追加扩展字段，但扩展不能替换、重命名或改变 canonical 字段：

```text
SoundBridgeExtensions
  image_relation: <与前后画面同步、领先、滞后、反差或重解释>
  mix_path: <从前景到背景、由远及近、受遮挡或主观收窄等>
```

`function`、`source`、`point_of_view`、`starts`、`crosses`、`resolves` 或 `viewer_effect` 答不清，就不使用声音桥。

### 4.2 五种功能

**确认**

声音与可见动作或空间因果一致，帮助观众定位路径、接触、距离或后果。若画面已足够明确且声音没有新增物理信息，只保留最必要节点声。

**提前预告**

后一 beat 的声源在画面显露前先进入，形成 `viewer_waits_for`。必须写方向、距离和解决节点；不能把无来源噪声冒充悬念。

**可解释误导**

声音的来源或意义暂时被遮挡，后一画面提供重解释。误导必须有真实声源和回看成立的因果，不随意欺骗观众。

**主观化**

声音范围、清晰度、动态、频段或距离随某角色感知改变。必须明确 POV owner、进入触发和退出节点；不把任意失真当“主观感”。

**连续**

环境底层、动作尾音、人声、呼吸或静默跨切延续，使观众理解仍在同一空间、动作或情绪状态。连续桥不是把所有声层原样复制，只保留真正跨点的声源。

### 4.3 跨点方式

技术方式只在选定功能后使用：

- 前一画面的声音延续到后一画面：保持因果、空间或情绪尾音。
- 后一画面的声音提前进入：先建立期待，再显露声源或结果。
- 事件余音跨点：接触、语言或结构响应的尾音覆盖剪点。
- 环境底层跨点：同一空间的持续声维持地理连续。
- 静默跨点：部分声层收住，留下极少声源把观众带入反应或新 POV。
- 画外人声引导：明确 owner、speech action、方向和何时入画 / 被解释。

不要在最终提示词中堆叠“延续桥、提前入声、余音桥、环境桥”等多个标签；写一条完整因果句即可。

## 五、声音 POV 与空间一致性

### 5.1 客观空间声

声源远近、方向、遮挡、反射与相机和主体的空间位置一致。前景声细节更多；远处声以方向和空间感为主；障碍会改变清晰度和高频；开合、材质和空间尺度决定尾音。

### 5.2 受限主观声

```text
pov_owner
→ perceptual_trigger
→ audible_range_and_priority_change
→ information_gained_or_lost
→ return_to_objective_sound
```

- 主观声场必须属于明确角色；
- 声音变化与呼吸、视线、身体状态、距离或信息冲击同步；
- 进入主观后，不应继续让角色不可能感知的细节保持同等清晰；
- 回到客观空间时，用环境底层、定位声源或可见反应重新建立地理关系。

### 5.3 声音与镜头距离

声音不必机械随景别变化，但所有偏离都要有功能：近景保留远声可强调空间压力；宽景突出细小近声可进入主观注意。写清这是客观距离、选择性注意还是信息桥，不让生成端猜测。

## 六、混音层级：写相对关系，不写后期参数

提示词只需说明前景、底层、节点突出、遮挡和衰减，不写具体分贝、插件链、母带参数或 DAW 工程。

```text
MixHierarchy
  foreground: <当前必须理解的人声 / 动作 / 声源>
  secondary: <提供反应或材质证据的次前景>
  bed: <低位连续环境>
  peak_event: <何时短暂突出，哪些层让位>
  occlusion_and_distance: <远近、方向、障碍带来的可听变化>
  decay: <峰值后如何退到背景>
  handoff: <前景如何交给下一声音、静默或画面>
```

规则：

- 一次只让一个关键信息成为听觉前景；
- 重要台词出现时，事件峰值和环境应短暂让位；
- 动作高潮可以短暂峰值，但峰值前有预备、峰值后有衰减和反应；
- 声音密度随画面负载调整，复杂视觉动作时减少同时需要理解的声层；
- 结尾降低无关噪声，保留一个与最后画面功能一致的余音、环境、呼吸或续接声。

## 七、声音、表演与对白的协作

- 角色声线变化要与权力、策略和压力同步；不是单独添加“颤抖声线”。
- 停顿可承担交流、呼吸、观察或声音交接；时长归属与重叠占用按 `dialogue-pace-and-voiceover.md` 处理，不重复扣除。
- 打断可由人物、制度提示、动作或环境事件触发，但必须改变 `local_outcome`。
- 重叠对白只在抢夺话语权、协作抢拍、遮住信息或误听时使用，且指定必须听清的前景句。
- 反应可先由声音发生，再由镜头找到主体；也可先见动作，声音余波滞后，强化后果。
- 能由动作与声音共同表达的信息，不再让台词复述。
- 画外音与画面并行不创造额外理解容量，仍需控制信息密度、语速、混音和退出点。

## 八、与剪镜、重构和长镜头的关系

### 8.1 切镜

声音桥可在切镜前建立下一信息，在切镜后保留前一行为后果。若声音已经完成信息揭示或情绪衔接，不必再用额外运镜重复同一功能。

### 8.2 镜内重构

焦点、blocking 或构图在同一镜头改变时，声音可提前指向新深度层、随遮挡改变清晰度，或在人物停下后把环境推到前景。声音也可建立空间质感、氛围和形式节奏，不必每次带来新信息或关系变化。

### 8.3 长镜头

长镜头不靠持续增大音量制造发展。用声源接近 / 远离、空间反射变化、人物语气、环境层让位、事件节点和静默组织内部 beat。每次听觉重构都应有触发和结果。

### 8.4 有意硬切

硬切可用于信息冲击、POV 断裂、情绪重置或形式节奏。需要精确控制时写清切断与残留的声层；连续叙事用余音或环境声保护空间，有意断裂则保持指定切口。

## 九、最后声音与最后一帧

结尾声音要与 `final_image_function` 一致：

```text
FinalSound
  image_function: <回答 / 反转 / 固化 / 余波 / 续接 / 主题压缩>
  foreground_exit: <台词或事件峰值何时结束>
  retained_source: <最后保留的明确声源>
  spatial_tail: <方向、距离、反射或衰减>
  viewer_effect: <让观众确认、重解释、等待或停留什么>
  continuity_anchor: <若需续接，下一片段应保持的声源状态>
```

台词默认在片段结束前收住，把末尾交给反应、环境、余音或静默。只有明确设计的未完成人声 / 声响才可作为续接锚点；禁止无意硬截。

## 十、内部写作槽位

```text
声音 POV：<客观空间 / 所属角色>，因<触发>在<节点>改变为<可听结果>。
环境底层：<声源系统>在<空间与材质>中持续，跨<beats>保持，因<来源>变化。
事件 / 拟音：<动作>作用于<接触点与材质>，从<预备>到<峰值>再到<衰减>，触发<反应 / 信息>。
人声：<owner>以<voice_print / speech_action>在<距离与遮挡>中发声，<前景优先级>，于<退出点>结束。
声音桥：以<function>组织<source>，其<point_of_view>从<starts>跨过<crosses>，在<resolves>解决，使观众<knows / feels / waits_for>；需要时另加<image_relation / mix_path>。
静默 / 余波：<trigger>后移除<layers>，只保留<sources>，直到<恢复 / 结尾 / 下一 beat>。
混音：<foreground>清楚，<bed>低位连续，<peak>短暂突出后<decay>，最终把注意力交给<下一声音 / 画面>。
```

这些字段是内部规划。最终提示词只写会影响生成的声源、节点、空间关系、前景优先级、桥接和结尾余波。

## 十一、反模式与修复

- **情绪词无法定位所需声音**：需要精确事件声时补声源、距离、节点或动态；用户只指定音轨氛围时可保留简洁情绪词。
- **用配乐替代戏剧行动**：优先用环境、呼吸、材质、事件、静默和声音桥组织节奏。
- **每镜重启环境**：建立片段级底层，只写有来源的变化。
- **所有声音同样响**：指定一个前景、一个底层和少量节点峰值。
- **人声被峰值盖住**：错开关键词与事件峰值，或让其他层短暂让位。
- **拟音与材质不符**：回到动作、接触点、材质状态、空间反射和衰减链。
- **声音桥无解决点**：补声源显露、意义重解释或衰减节点；无法补就删除。
- **声音误导无因果**：建立真实声源与回看成立的解释，不随意欺骗。
- **主观声无 owner**：明确所属角色、感知边界、进入与退出触发。
- **相对静默与纯静音混用**：相对静默按需保留少量声源；纯静音不保留微声、环境底噪或呼吸。
- **画外音伪造容量**：按对白计时参考核对实际区间并集、非语言禁占区与理解负载；字符 / 语速只作首稿估算。
- **结尾被硬截**：让人声 / 峰值提前退出，以余音、环境、反应或有意续接声收束。

## 十二、交付前检查

只检查实际使用的声层和控制；纯静音核对无声约束即可，不展开声音计划。

1. 需要精确控制的重要声音是否明确声源、必要节点与适用的空间/衰减关系？
2. 声音是否符合观看目标；是否没有为解释简单声音或情绪词而扩写？
3. `sound_point_of_view` 是否明确，主观变化是否有 owner、触发和退出？
4. 环境底层是否在同一空间跨镜连续，变化是否有来源？
5. 动作 / 事件音是否绑定路径、接触、材质、峰值和后果？
6. 人声是否归属清楚、符合角色声线，并避开关键事件峰值？
7. 声音桥是否完整使用 canonical `function / source / point_of_view / starts / crosses / resolves / viewer_effect`，且扩展字段没有替换最小契约？
8. 可解释误导是否有真实因果，提前入声是否有显露节点？
9. 切镜 / 重构的声音是否服务信息、POV、关系、情绪、环境氛围或指定节奏，且没有擅自改写有意重复？
10. 相对静默与纯静音是否区分，保留或删除的声层是否符合用户要求？
11. 混音是否只有一个主要前景，峰值后是否有衰减与注意力交接？
12. 台词是否按对白计时参考核对区间并集、时间位置与片尾余量，且未重复扣时？
13. 最后声音是否服务最后一帧功能，或形成明确续接锚点？
14. 是否没有额外添加用户未要求的配乐；编辑任务是否保留原片中受保护的音乐与其他声音？
