# 特效设计维度库

本文件用于单片段视频提示词中的视觉与物理变化控制。它只提供跨题材的决策维度、可观察特征、关系规则和反模式，不提供题材菜单、IP、固定场景或可直接复用的特效样本。适用控制写进对应时间片的 `视效/VFX` 字段。

视觉变化控制的核心目标是**实体化当前 brief 需要的可见变化**：让相关事件具备体积、材质、尺度、路径、接触反馈和残留结果，而不是停留在平面装饰或抽象形容。低变化或无人工变化的任务不强行奇观化、不输出占位；只有 brief 和物理因果需要时，才写实际存在的光学、材质、介质或状态变化。

## 好特效的定义

高质量的可见变化不是更亮、更炫或更多元素，而是能回答：从哪来、往哪去、碰到什么、对象如何响应、结束后留下什么。只选择当前事件相关的维度，不为填满表格制造内容。

## 十一个编写维度

| 维度 | 高质量方向 | 可观察特征 |
|---|---|---|
| 体积 | 占据空间，有清晰厚度、边界和占位感 | 有物理边界、可测厚度、占据可见空间，不是贴片 |
| 材质 | 有可感知的重量、触感、光泽、颗粒、液态/气态/固态属性 | 表现材料特性与光学反应，不是无质感的光 |
| 尺度 | 让主体与环境形成压迫、包围、托举、撕裂、吞没或改造关系 | 特效与人物/环境的相对大小产生视觉冲击 |
| 想象力 | 机制有新鲜感，把概念转成意料之外但成立的视觉事件 | 非套路、非通用光效、概念完整 |
| 生成机制 | 交代特效从何处出现、由什么触发、如何成形、如何扩散 | 有因果链：触发点 → 生成过程 → 扩散逻辑 |
| 运动路径 | 写清方向、速度、层级、阻力、碰撞、回弹、旋转或塌缩 | 运动有物理约束、分层感、方向明确 |
| 接触反馈 | 与地面、空气、衣料、发丝、道具、建筑或自然介质发生真实接触 | 能列出特定接触对象，产生可见变形/扰动 |
| 环境反应 | 空间、光线、介质、表面、结构或远景随事件变化 | 周围元素按当前材质和受力关系产生连锁反应 |
| 声音反馈 | 声音有来源、距离、材质感、冲击力和衰减过程 | 声音有空间感、材质感、衰减轨迹 |
| 残留结果 | 事件结束后留下余光、碎屑、气流、痕迹、回声、表情或空间变化 | 特效后有可见的持续状态 |
| 镜头承载 | 景别、角度、运动和焦点服务于特效层级，而非堆砌镜头词 | 镜头调度与特效体积/运动同步，非装饰 |

## 因果链最小骨架

任何一段物理/视效变化，至少写清这条链：

```text
来源（从哪发生） → 路径（沿什么方向/形状/速度扩散） → 接触点（影响哪个主体/物体/地面/空气/光线） → 材质响应（形变/位移/破坏/反射/悬浮/状态转换/表面变化） → 余波（残留物/空间回响/介质扰动/光影残留/碎裂结果/静默/姿态变化）
```

缺少其中任一环，特效就会显得"凭空出现"或"打完即消失"。

内部变化控制最小写法；最终提示词只渲染适用内容，不显示这些内部键：

```text
change_control:
  source: <由 brief 与事件因果推导的来源>
  path_and_timing: <方向 / 速度 / 形态 / 起止节点>
  interaction: <与主体 / 物件 / 空间发生的遮挡、反射、接触或材质响应>
  peak_or_transition: <变化的峰值、转折或状态转换>
  residue_or_recovery: <事件后实际留下或恢复的状态>
```

## 机制推导问题

不从机制菜单抽取默认特效。依据 brief、主体状态和物理因果逐项判断：

- 变化由什么事件触发，触发前后状态差异是什么？
- 变化是在表面、体积、介质、空间关系、光学表现还是运动状态中发生？
- 它沿什么方向和时间路径推进，哪些边界、阻力或遮挡限制它？
- 它接触哪些对象，各对象按何种材质或结构产生响应？
- 观众必须看清哪一个峰值、转折、衰减或恢复节点？

若这些问题不能从 brief 推导出必要变化，就不新增人工视觉事件。

## 变化强度与连续性

- **低或无人工变化**：自然省略变化控制，不输出“无 VFX”说明；仅保留事件理解所必需、由 brief 支持的实际状态变化。
- **局部变化**：锁定一个主要来源、一条路径、一个关键接触与一个可辨结果，避免把多个机制堆进同一拍。
- **强变化**：除来源和路径外，补遮挡、材质响应、环境影响、峰值/衰减及跨镜连续性，使主体、镜头与空间处于同一可见因果链。
- **多次变化**：每次必须承担不同的叙事或控制功能；后一次可以升级、转移、反转、衰减、解决或重新解释前一次，不强制更大、更亮或更密。没有新增信息、关系、行为或状态结果的重复变化应删除。

## 反模式（出现即判不合格）

- 平面装饰、通用发光图案或没有来源与接触的抽象效果。
- 特效凭空出现，没有来源、触发、成形或路径。
- 巨大事件结束后没有任何残留。
- 镜头罗列"推拉摇移"却不引导注意力。
- 只调亮度/粒子数充数，材质、接触、余波全缺。

## 自检

收尾时只对 brief 需要的视觉/物理变化提问：它是什么、从哪来、往哪去、何时转折、碰到什么、对象如何响应、结束后留下什么，镜头是否服务其体积与路径？不适用时是否已自然省略而没有占位？多个变化是否各有不同功能而非自动升级？这些问题答不清，就按因果链补齐或删除无功能变化。
