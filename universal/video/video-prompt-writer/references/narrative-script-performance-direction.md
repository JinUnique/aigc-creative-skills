# 叙事、对白与表演方向方法库

本文件负责单片段视频提示词的叙事变化、戏剧行动、`DialoguePlan`、角色声线、信息释放与表演方向。它把“要说什么”先编译成“人物在用语言和行为对谁做什么”，再把必要结果渲染进时间轴；它不是台词清单，也不要求最终提示词暴露内部 schema。

使用边界：只提供抽象规则、占位槽、动作维度和检查问题；不提供固定人物、固定场景、固定 IP、固定剧情、固定对白、固定笑点或可复用成片样本。不得把创作者姓名当作风格 preset。用户点名在世编剧或作者时，只提取并使用可说明的通用 craft dimensions，例如信息密度、句长、直接程度、潜台词强度、节奏、权力交换和表演留白；最终输出不写“某某式”，也不复刻其作品语句。研究人物姓名若因来源审计出现，只能留在 provenance / 边界说明中，不能进入运行时选择项。

---

## 一、先锁定一个可见的戏剧变化

单片段不是故事梗概。无论有无对白，都要让人物经过一次欲望、选择或状态变化，并让观众从画面、声音或行为中读到结果。

### 1.1 NarrativeUnit 内部槽位

```text
NarrativeUnit
  dramatic_question: <观众等待哪件事被回答或升级>
  start_state: <信息 / 关系 / 权力 / 行为 / 情绪 / 空间起点>
  subject_objective: <主体此刻试图改变谁或什么>
  obstacle: <使目标不能直接完成的阻力>
  choice: <人物必须采取或放弃的行动>
  state_change: <片段结束时真正变化的项目>
  evidence: <证明变化的动作 / 反应 / 声音 / 物件 / 空间结果>
  final_image: <把结果或未完成压力压缩成可读画面>
```

变化可以落在信息、关系、权力、目标、行为、情绪、空间、物件或后果，但一个片段只保留一个主变化；其他变化必须服务它。

### 1.2 戏剧阻力不等于反派或争吵

阻力只要求人物不能无代价地直达目标。可从以下维度推导，按当前 brief 选一项主阻力，必要时加一项次阻力：

- 环境：距离、噪声、遮挡、重量、温度、移动介质或空间限制改变行动方式。
- 制度 / 程序：权限、规则、角色职责、顺序、证据要求或公开场合限制可说与可做的事。
- 时间：截止节点、即将发生的状态变化、短暂机会或必须等待的过程。
- 关系：双方都在保护某种关系、边界、信任、面子或承诺，但优先级不同。
- 信息：误解、不完整线索、认知差、不能确认或不宜公开的信息。
- 自我矛盾：表面目标与真实需要相冲突，行动越接近目标，内在代价越明显。
- 不可明说欲望：人物需要某种回应，却不能或不愿直接提出。
- 身体 / 物理：疲惫、疼痛、失衡、呼吸、惯性、摩擦或材质反馈。

温柔、合作、照护或共同解决问题的场景也要有不同的即时目标、有限资源、犹豫或不能直说的需要；冲突强度可以很低，但交流前后必须出现选择和状态变化。无人格化反派、无争吵完全成立。

## 二、节拍：触发、策略行动、反应、变化

节拍是一次可读的小变化，不等于一次切镜。一个长镜头可含多个节拍，多镜头也不能用重复 coverage 伪造节拍。

```text
Beat
  trigger: <新声音 / 新信息 / 视线 / 动作 / 空间或物件变化>
  objective_now: <人物在这一刻要改变什么>
  action: <语言动作或非语言动作>
  resistance: <对方 / 环境 / 制度 / 时间 / 自我如何回应>
  reaction: <身体、视线、声音、位置或沉默的可见结果>
  local_change: <本节拍增加的信息、关系、行为或权力变化>
```

可用功能包括建立、试探、阻挡、交换、误导、揭示、升级、停顿、反转和落点。选择功能后必须改写成当前主体的可表演行为，不把功能名直接堆进提示词。

时长越短越应保留“触发 → 行动 → 反应 → 落点”；时长增加也不自动增加角色、镜头或台词。复杂节拍的真实时长、非语言余量和台词容量由 `dialogue-pace-and-voiceover.md` 校验。

## 三、DialoguePlan：把对白作为戏剧行动编译

对白写作必须先完成内部 `DialoguePlan`。默认不向用户展示字段名；最终只渲染必要台词、声线、停顿、重叠、表演和交流结果。

### 3.1 完整内部契约

```text
DialoguePlan
  duration: <片段总时长>
  reserved_nonverbal_time: <仅含独立于台词交付的动作 / 反应 / 环境 / 声音桥独占节点 / 结尾余波>
  usable_speech_time: <duration - reserved_nonverbal_time>
  drafting_rate_estimate: <仅用于首稿字数估算；不得当作最终验证>

  per_character:
    - character_id: <角色标识>
      target: <想影响的对象 / 制度 / 自己>
      surface_want: <角色愿意公开表现的即时目标>
      real_need: <驱动行为但未必自知或愿意承认的需要>
      obstacle: <此刻无法直接完成目标的阻力>
      concealment: <正在隐藏、淡化或避免说出的内容>
      tactic: <当前主要语言策略；可随 exchange 改变>
      voice_print:
        experience_trace: <个人经历如何影响观察和措辞，不用身份刻板印象>
        relationship_position: <面对该 target 时的熟悉度、义务、边界与历史>
        current_objective: <这句话此刻要换取什么>
        current_pressure: <时间、风险、被观察、身体或情绪压力>
        vocabulary_register: <词汇层级、具体/抽象程度、专业词使用范围>
        syntax_length: <短句 / 混合句 / 长句及其变化条件>
        directness: <直接、迂回、暗示、回避的程度>
        rhythm: <停连、重复、修正、抢拍、留白的个人节奏>
        politeness_and_power: <礼貌如何服务边界或权力，不等同阶层标签>
        emotional_leakage: <声音或措辞在哪些点泄漏真实压力>
        verbal_habit: <可选且低频的组织习惯，不做口头禅 caricature>

  power_arc:
    power_start: <谁能定义问题、控制时间/空间/信息或退出>
    transfer_trigger: <哪条信息、行动、沉默、位置变化使权力转移>
    power_end: <交流结束后谁获得、失去或重新定义了什么控制权>

  information_ledger:
    audience:
      knows: <观众已知>
      infers: <允许观众推断>
      waits_for: <观众等待确认>
    per_character:
      - character_id: <角色标识>
        knows: <确定知道>
        believes_or_misreads: <相信或误判>
        cannot_say: <不能 / 不愿公开>
    released: <本片段必须释放的信息、释放者和节点>
    withheld: <本片段刻意保留的信息及保留理由>

  exchanges:
    - speaker: <说话者>
      target: <被影响对象>
      action: <试探 / 回避 / 施压 / 讨价 / 安抚 / 掩饰 / 诱导 / 切断 / 承认等可表演动词>
      surface_meaning: <字面在说什么>
      subtext: <真正想让对方做、相信、停止或暴露什么>
      local_outcome: <对方行为、关系、信息或权力发生的局部变化>
      information_released: <该轮释放的信息；没有则写 none>
      information_withheld: <该轮仍保留的信息>
      visible_performance: <视线 / 呼吸 / 手部 / 重心 / 距离 / 声音证据>
      pause_overlap_or_interruption: <停顿 / response gap / 重叠 / 打断 / 被动作或声音切断及其功能>
      measured_delivery_duration: <该轮从交付准备到交接结束的完整实测时长，包含呼吸、句内停顿、response gap、重叠与打断>
```

`surface_want` 与 `real_need` 可以一致，但若完全一致，仍需通过阻力、策略选择或代价产生戏剧行动。`local_outcome` 不能只写“说完”；它必须说明信息、关系、行为或权力的增量。

### 3.2 编译顺序

1. **锁变化**：先写交流前后哪个状态改变，不先起草漂亮台词。
2. **定欲望**：分别写每个角色的 `surface_want`、`real_need` 和 target；不能只写主角。
3. **建阻力**：选择人物外或人物内阻力；不自动制造反派、争吵或高声量。
4. **做信息台账**：区分观众知道、各角色知道/误判、必须释放与应该保留的信息。
5. **标权力弧**：权力是定义问题、控制信息、时间、空间、行动或退出的能力；写清起点、转移触发、终点。
6. **选动作动词**：每轮只选一个主 `action`，让下一轮由上一轮结果触发，而不是轮流陈述立场。
7. **写潜台词**：区分字面句与真正目的；含蓄场景允许沉默、错位回答或动作承担隐藏内容。
8. **生成声线**：从经历、关系、目标、压力、词汇、句长、直接程度和节奏生成句形。
9. **绑定表演**：写声线变化、停顿、重叠、打断及对应的身体或空间反应。
10. **时长编译**：先只扣除独立非语言节点得到 `usable_speech_time`，再实测每轮完整 `measured_delivery_duration`，以逐轮总和和可用说话时间比较；呼吸、停顿、response gap、重叠和打断已经在交付时长内，绝不再次扣时。超载就删减，不用加速掩盖。
11. **删除冗余**：没有信息、关系、行为或权力增量的句子，删除或转为动作、反应、声音、物件或静默。

### 3.3 对话机制只选一到两种

机制用于组织攻防，不是形式花活：

- 断言 / 重定义：一方定义问题，另一方改变问题框架。
- 提问 / 回避：问题索取信息，回答转移目标或暴露不能说的内容。
- 提议 / 隐含代价：表面合作，真实交换条件通过行为或停顿显现。
- 指控 / 降级：一方抬高压力，另一方缩小、具体化或拒绝其前提。
- 承认 / 打断：信息将改变关系，但被人、动作、制度或环境切断。
- 安抚 / 情绪泄漏：策略保持温和，身体或节奏暴露真实风险。
- 重复 / 意义改变：同一措辞因新信息、权力或关系变化获得新功能。
- 沉默 / 权力转移：不回答迫使对方补充、退让、暴露或改变行动。
- 话语 / 画面反证：字面维持表象，动作、物件或空间结果揭穿它。

多人或重叠对白要先确保主行动线可懂：一次只让一个信息成为前景；重叠只用于抢夺话语权、掩盖、误听或节奏转折，并写清观众必须听清哪一句。

## 四、角色声线：从个人条件生成，不从标签套取

角色声线不是口音清单，也不是给身份分配一种作者腔。它由人物个人经历、与 target 的关系、当下目标和压力共同改变用词、句长、直接程度、节奏与情绪泄漏。

### 4.1 声线推导链

```text
个人经历留下的注意习惯
+ 与当前对象的关系位置和历史
+ 此刻要换取的结果
+ 当下时间 / 风险 / 被观察 / 身体压力
→ 词汇层级与具体程度
→ 句长和句法完整度
→ 直接 / 迂回 / 回避程度
→ 停连、修正、重复、抢拍与沉默
→ 情绪从哪里泄漏
```

- 经历只决定人物更容易注意和怎样组织证据，不预设其智力、道德、粗俗度或情感能力。
- 关系会改变同一人物的声线；面对不同 target，称呼、礼貌、解释量、直接程度和停顿可以不同。
- 压力可以让既有声线收紧、破裂或反常，但变化要有触发点。
- `verbal_habit` 只作为低频辨识点，不能每句重复，更不能替代行动目的。
- 禁止以地域口音、阶层、职业、年龄、性别、族群或其他身份刻板印象替代 `voice_print`。用户明确需要口音时，也只能将其作为表音执行要求，不能据此推断人格、教育或权力。

### 4.2 声线差异必须可操作

不要只写“甲冷静、乙活泼”。至少让两位角色在下列三个维度存在有因果的差别：

- 观察对象：先说事实、关系、风险、规则还是感受。
- 词汇具体度：可验证名词与动作，或抽象概括与隐喻。
- 句长与修正：完整句、截断句、自我修正、反问或留白。
- 直接程度：明说请求、给选择、暗示、回避或把压力转给对方。
- 节奏：先反应后说、边做边说、等对方补充、抢话或让沉默工作。
- 情绪泄漏：音量、呼吸、称呼变化、语法破裂、重复或突然精确。

差异必须服务目标和关系，不能为了“好区分”制造夸张人格。

## 五、信息、潜台词与语言经济性

### 5.1 信息台账纪律

- 观众、speaker 和 target 的“知道”分开记录，不能把作者知道的内容默认给所有人。
- 每条 released 信息必须有释放者、接收者和后果；只释放但无人改变行为的信息应删除或延后。
- withheld 不是故弄玄虚，必须保护关系、策略、风险、制度边界或后续戏剧问题。
- 允许观众先于角色知道、晚于角色知道或与角色同时确认，但每个选择都要影响 `viewer_waits_for`。
- 对白不是唯一信息渠道；视线、动作、物件、位置、声音先入和反应都可释放信息。

### 5.2 潜台词不是含糊

潜台词成立时，字面句仍要有现场功能，同时真实目的由措辞选择、回避点、身体动作、停顿或对方反应显现。若场景本就需要直接确认、紧急指令或清楚边界，不强行绕弯；潜台词测试要求“适合含蓄的场景不能表里完全重合”，不是要求所有台词都隐晦。

### 5.3 画面优先

能由可见动作完整表达的句子应删掉。画面与台词可以互补、错位或互证，但不能逐句互相复述。信息密集时先问：

1. 这项信息是否为当前动作所必需？
2. 能否由表演、位置、物件、声音或对方反应表达？
3. 必须说时，能否把解释改成对 target 的行动？
4. 仍然超载时按 `delivery_intent` 路由：`single_clip` 标 blocked 并请求授权；`story_complete` 编译连续 Prompt Pack；`auto` 按语义与容量规则判断。

## 六、表演编译：把策略写进身体和声音

情绪结论不能直接替代表演。每个关键 exchange 至少绑定一项可见证据和一项可听证据，且证据要随权力或策略变化。

- 视线：锁定、回避、等待对方先移开、转向共同目标或画外压力。
- 呼吸：屏住、变浅、抢在开口前吸气、句尾失去气息或长呼气释放。
- 面部：下颌、眼睑、嘴角、眨眼、聚焦变化，不用“大为震惊”概括。
- 手部 / 物件：停住、继续完成、撤回、递交、占住、放下或改变所有权。
- 重心 / 距离：前倾、退让、并肩、挡住路径、让出中心、靠近或退出。
- 声音：音量、音高范围、咬字完整度、句长、停连和情绪泄漏。
- 反应延迟：立即回应表示预判或控制；延迟回应可表示计算、受创、误判修正或拒绝被迫回答。

停顿、response gap、重叠和打断都占交付时长且必须做事；它们进入对应 exchange 的 `measured_delivery_duration`，不进入 `reserved_nonverbal_time`，也不在比较前后二次扣除：

- `pause`：迫使对方补充、让信息落下、保护不可说内容或给反应空间。
- `overlap`：争夺定义权、配合完成、遮住关键词或显示双方不同优先级。
- `interrupt`：由人物、动作、制度提示或环境事件改变策略；不能只为制造热闹。
- `line_cut_off`：未完成部分必须能由画面、声音或观众推断承接。

## 七、画外音的叙事边界

画外音可以压缩不可见信息、连接时间、建立主观距离或提前引导注意力，但不能成为作者说明书。

内部至少记录：

```text
voiceover_owner: <明确主体或声源>
relationship_to_image: <同步 / 补充 / 反差 / 先于画面 / 延续上一镜>
information_function: <必须补充的内容>
voice_print: <与该角色一致的词汇、句长、直接程度与节奏>
spatial_quality: <近 / 远 / 隔着障碍 / 记忆化 / 主观化，但不写无依据特效>
exit_point: <何时结束，把结尾交给动作、反应或声音余波>
```

画外音与画内动作并行不代表获得额外时长；它仍占用观众的理解带宽，仍需把呼吸、句内停顿、response gap、重叠和打断纳入逐轮完整 delivery 实测，并检查混音可懂度，不能用起草语速估算代替验证或二次扣时。

## 八、对白验收：不通过就删、改动作或重编译

每段对白逐项测试：

1. **换人测试**：把甲的台词交给乙，是否仍几乎成立？若成立，重做 `voice_print`、目标或策略。
2. **行动测试**：每句是否在对 target 试探、回避、施压、安抚、诱导、切断、承认或做其他具体事情？纯说明改写。
3. **变化测试**：exchange 后是否新增信息、改变关系、触发行为或转移权力？没有增量就删除或转为动作。
4. **潜台词测试**：适合含蓄时，`surface_meaning` 与真实目的是否存在可读差异？若完全重合，检查是否过度解释。
5. **画面替代测试**：动作、视线、物件、blocking 或声音能否更清楚表达？能则删台词，把时间还给表演。
6. **朗读 / 时长测试**：`reserved_nonverbal_time` 是否只含独立非语言节点，且逐轮 `measured_delivery_duration` 是否已在真人朗读或目标 TTS 下完整纳入呼吸、句内停顿、response gap、重叠和打断，再以其总和对照 `usable_speech_time`？未实测只能标记起草估算，不能声称已验证，也不能把交付内停顿二次扣除。
7. **角色一致性测试**：词汇、句长、直接程度、节奏、礼貌策略和情绪泄漏是否符合经历、关系、目标和压力？
8. **信息台账测试**：角色有没有说出自己不知道的内容，或无理由释放应保留的信息？
9. **权力测试**：`power_start → transfer_trigger → power_end` 是否能从语言、行为或空间证据读出？
10. **可懂度测试**：多人、抢话或重叠时，观众必须听清的前景信息是否唯一且不被环境/事件音盖住？
11. **字幕约束测试**：有对白不等于生成屏幕文字；未要求字幕时继续保持禁止字幕。

任何台词若既无信息、关系、行为、权力增量，也不建立独特声线，应删除。删除后出现的空白优先交给反应、环境、声音桥或最后一帧，而不是补一句同义话。

## 九、内部写作槽位与交付检查

可在写作前使用下列内部槽位；最终提示词只渲染会影响生成的内容：

```text
叙事变化：<start_state> 经<阻力与选择>变为<state_change>，以<evidence>证明。
角色行动：<角色>表面要<surface_want>，真实需要<real_need>，对<target>采用<tactic>，隐藏<concealment>。
权力弧：<power_start>，因<transfer_trigger>转移，最终<power_end>。
信息差：观众<knows / waits_for>；角色分别<knows / misreads>；本段释放<released>，保留<withheld>。
对白轮次：<speaker>以<action>作用于<target>，字面<surface_meaning>，潜台词<subtext>，导致<local_outcome>。
声线：由<experience + relationship + objective + pressure>生成<register + syntax + directness + rhythm + leakage>。
表演：<视线 / 呼吸 / 手部 / 重心 / 距离 / 声音>在<策略或权力变化节点>发生可读变化。
时长：总时长<duration>，独立非语言保留<reserved_nonverbal_time>，可用说话<usable_speech_time>；逐轮完整交付实测<measured_delivery_duration>并汇总比较，起草字数估算不替代实测。
落点：台词提前结束，最后停在<行为 / 关系空间 / 物件状态 / 反应 / 声音余波>。
```

交付前确认：

- 片段只有一个主戏剧变化，欲望、阻力、选择和结果完整；
- 即使温柔合作或无对白，人物也有目标差、选择和状态变化；
- DialoguePlan 覆盖角色、exchange、权力弧、信息台账、节奏机制、独立非语言时长和逐轮完整交付时长；
- 声线来自个人经历、关系、目标和压力，没有身份刻板印象；
- 每句台词都能表演、能改变现场，且不能被任意角色互换；
- 台词没有复述画面、朗读设定或替作者解释；
- 表演与声线随策略、信息和权力变化；
- 台词经朗读 / TTS 逐轮校时，总 `measured_delivery_duration` 不超过 `usable_speech_time`，且没有重复扣除交付内呼吸、停顿、response gap、重叠或打断；结束前仍留独立动作、反应、环境和余波；
- 最后一帧能显示新的信息、关系、行为、权力或未完成压力；
- 最终输出不使用创作者姓名作为风格标签，也不出现“某某式”。
