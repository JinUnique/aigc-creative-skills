# 对白计时、重叠与画外音

本文件是对白时间计算的唯一规则来源。对白策略和戏剧表演见 [叙事与表演](narrative-script-performance-direction.md)，声层、声桥和混音见 [声音设计](sound-design-foley-ambient-mix.md)。

## 1. 先排时间，再算容量

锁定总时长、必要动作、观察/反应和片尾状态。把确实不能与语言并行的节点设为 `reserved_nonverbal_intervals`；同时发生的动作不重复扣时。呼吸、句内停顿与归属某轮的交接间隔进入完整 delivery 区间，只计一次。

```text
duration = 本生成段总时长
reserved_nonverbal_time = length(union(reserved_nonverbal_intervals))
usable_speech_time = duration - reserved_nonverbal_time
speech_occupied_time = length(union(delivery_intervals))
```

一个预算能通过，必须同时满足：

1. 所有区间在本地 `[0, duration]` 内，起点早于终点，事件顺序与用户要求一致。
2. `speech_occupied_time <= usable_speech_time`。
3. 发声/交付区间没有侵入要求独占的非语言节点；总量够用不代表局部排得下。
4. 已锁定台词按实际语速和表演完整交付；重叠时听觉前景清楚。
5. 片尾所需反应、余音或稳定状态有实际位置。

只有互不重叠的完整 exchange group 才能直接求时长总和。多人重叠时逐 speaker 相加会把共享时间重复计算；用真实起止区间的并集，或先组成不重叠的 exchange group。并集只解决时间占用，不证明听得清。

## 2. 计时短例

这些只解释计时，不提供台词或剧情模板。

| 已知安排 | 判断 |
|---|---|
| A `[0,4]`，B `[3,7]`，片尾 `[7,10]` 独占反应 | 交付区间并集为 `[0,7]`，占 7 秒；不是 4+4=8 秒。3 秒尾部可保留 |
| 两轮分别为 `[0,3]`、`[4,7]` | 发声区间共 6 秒；中间 1 秒若属于交接间隔，应按实际归属纳入一次，不能忽略排程间距 |
| 10 秒片段中必须在 `[4,6]` 纯观察，某句实际 `[3,5]` | 即使总对白少于 8 秒，仍与禁占区冲突，须重排 |
| 人声与可并行手部动作同时发生 | 不把该动作再次加入独占非语言时间；仍检查表演与听觉理解能否并行 |

区间共享端点不构成有持续时间的重叠。语言跨画面剪点可以形成声音桥，不要求每句在切镜前结束；跨独立生成段时须有实际音频续接方案，不能只用一句“保持连续”保证声音完整。

## 3. 首稿估算

无朗读或目标 TTS 时可保守估时，并标记 `unverified_estimate`。以下只是起稿观察带，不是模型上限，也不是已验证能力：

| 语速 | 中文字符/秒起始区间 | 适用条件 |
|---|---:|---|
| 克制/留白 | 2.5–3.5 | 反应、低声、复杂情绪或较多停顿 |
| 自然对话 | 3.5–5 | 常用短句、自然气息与换轮 |
| 明确加速 | 5–6.5 | 短句、利落节奏，需校时与可懂度检查 |
| 极短爆发 | 7–9 | 明确的极短抢话、喊叫或节奏表演，不能作为普通对白预算 |

数字、缩写、外语、专有词和绕口音节应按实际读法估计。用户锁定的原文保持不变；用于计时的口语展开与最终字幕/台词文本分开。情绪强烈也可能使停顿变长，不能自动加速。动作与非语言余量按实际节点安排，不固定预扣 30%。

## 4. 实测与证据

1. 准备实际会说出的文字，标出需发声的呼吸、犹豫、停顿、打断与重叠；表演说明不作为朗读文字。
2. 使用目标语言、声线、情绪和速率朗读，或使用目标 TTS；不以另一种声音的速度冒充目标结果。
3. 每轮记录说话者、完整交付起止、前景句与非语言禁占区。TTS 未实际合成重叠和停顿时，不能声称已测完整排程。
4. 按第 1 节核对时间，并检查台词是否避开必须听清的事件峰值、片尾是否自然收住。
5. 台词、声线、速率或排程改变后，重新验证受影响区间。

内部状态保留 `verified_human_read`、`verified_target_tts`、`unverified_estimate`，同时记录来源；用户提供实测时标明是用户提供，不声称由本次工具测得。真人朗读/TTS 可行不等于视频模型最终人声、口型或音画同步已验证。

## 5. 重叠、停顿与超载

重叠适用于抢话、协作、误听或刻意层次，明确哪句是必须听清的前景。两条都需完整理解时，优先错开。停顿可以是理解、自然呼吸、交流或表演节奏，不要求每次都有权力转移。

超载时先去掉未锁定的重复说明和无增量语言，再尝试合理重排可并行节点。用户锁定的台词、事件或时长不能擅改；按主 skill 的单片/完整故事意图处理删改、延时或分段。把对白改成旁白不会增加物理时长或理解带宽。

## 6. 画外音与声音空间

“声源是否入画”与“是否属于故事空间”是两条不同轴：

| 类别 | 声音职责与空间 |
|---|---|
| 镜外角色对白、提前入声、上一镜人声延续 | 仍可属于故事空间；保持角色身份、距离、方位和适用的遮挡/反射 |
| 内心独白或主观人声 | 明确所属主体与进入/退出条件；声音可按主观设计处理 |
| 面向观众的旁白 | 明确叙述者或稳定叙述声音；不必位于画中房间，也不自动受画中墙体遮挡 |

需要控制时才规划 `owner / mode / relationship_to_image / timing / priority / exit_point`；场景内声音追加空间关系。音色身份与语言风格分开，词汇、句长或口音描述不能保证同一实际声纹。

旁白可补画外信息、组织时间或产生反差，不复述观众已看懂的全部动作。重要语言出现时安排适当混音优先级；收尾自然或使用已确认的声音续接方式。

## 7. 检查

- 估算与实测来源是否清楚，是否使用了实际读法和完整交付区间？
- 重叠、交接间隔、呼吸和动作是否只计一次？
- 除总量外，是否检查了时间位置、顺序和非语言禁占区？
- 台词、事件和结尾是否完整，必要前景是否可懂？
- 旁白、镜外对白与主观声音的空间处理是否符合各自归属？
- 最终正文是否只包含执行需要的台词、归属、节点和约束，没有内部核算表？
