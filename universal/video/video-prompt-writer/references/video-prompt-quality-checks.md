# 视频提示词质量检查

区分提示词正确性、创作适配和实际生成结果。结构检查通过不代表成片已验证；不以字数、术语数、标签数或自评高分证明效果。

核心目标是更好的故事与视听呈现。精简 skill 的低价值说明是一种手段，不能变成缩短最终提示词的要求。

## 1. 正确性

仅检查适用项；不适用项不需要补写内容。发现问题时定位到受影响的事实、段或关系。

| 检查面 | 通过条件 |
|---|---|
| 用户意图 | 原文台词、关键事件、顺序、时长、风格和修改范围保留；单片未被静默拆分，完整故事未被删改 |
| 素材与模式 | 素材名称真实、职责明确；参考外观、编辑对象和原生首尾帧绑定不混用 |
| 能力依据 | 声称可执行的模式、时长档、参考限制有当前模型/入口依据；未知与实测不混淆 |
| 时间 | 已要求的时间码连续覆盖，各段本地从 0 开始；动作有完成时间，必要反应和尾帧有位置 |
| 对白 | 使用实际交付区间或诚实估算；重叠按时间区间并集计占用，同时单独检查可懂度与非语言禁占区 |
| 连续性 | 适用的身份、方向、位置、物件状态、光线、声音和接触结果前后相容；跨段锚点进入正文 |
| 指令兼容 | 相机、主体运动、焦点、风格、声音来源与约束没有无意冲突；有意变化有对象和节点 |
| 格式与容量 | 满足用户/下游指定结构及实际长度限制；未指定模板时允许自然段和可选字段 |
| 交付洁净 | 一个生成单元一个代码块；复制内容没有内部方案、来源审计、评分、假素材或模板占位 |
| 信息密度 | 没有同段重复基线、无作用的释义、凑字段的细节或未获授权的创作扩张 |

时长与首尾帧问题按 [模式与平台](generation-modes-and-platforms.md)、[对白计时](dialogue-pace-and-voiceover.md)、[容量与分段](story-capacity-and-prompt-pack.md) 核实，不在本文件另建公式。

## 2. 根据用户目标评估

选择当前作品需要的维度，不把下表全部启用。

| 目标 | 评估重点 | 不作为默认加分项 |
|---|---|---|
| 观察、氛围、建筑或物体展示 | 构图、尺度、材质、光线与观察节奏是否共同支持指定审美 | 人物冲突、剧情反转、镜头数量 |
| 戏剧、对话 | 信息与关系推进、表演留白、台词自然度与可懂度 | 每轮都抢话、每镜都情绪转折 |
| 动作或特效 | 关键路径、接触/作用机制、空间可读性、后果与残留 | 同时运动的元素数量、光效强度 |
| 编辑与延长 | 改动准确、保留项稳定、时间/空间交接成立 | 全片重设计、新角色或新风格 |
| 蒙太奇或实验影像 | 用户指定的视觉、主题、声音或节奏组织原则 | 强行补同一故事的线性因果 |
| 多条独立创作 | 输入差异得到表达，自由维度有实质变化 | 为新颖而破坏已锁定风格与连续性 |

给出具体问题及其影响即可。无特效、无对白、固定机位和持续平静都可以是完整设计。用户要求量化评审时，先确定适用维度、证据与分值含义；不套通用“总分 >90、单维度 >=16”的门禁。

## 3. 修复与停止

1. 先修正确性错误，再检查作品是否已有适合故事的正向制作选择：场景/人物形象、关键表演、观看位置与镜头组织、光色、声音和节奏。只看故事有没有漏项不够。
2. 故事创作在未锁定制作维度充分设计；局部修改遵从最小改动范围，仅需改色、缩句或补焦点时不重写全部人物和分镜。
3. 每轮复查受影响的约束和邻接状态；改动时间轴则复核整段覆盖，改动交接则检查相邻段。
4. 交付前确认：故事和情绪能被观看者读懂，适用的制作选择形成一致视听方案，正文包含执行该方案所需信息，且正确性问题已解决。平铺故事、只给禁令或为了简短省掉关键表演与声画设计时继续改进。遇到缺素材、互斥硬约束或不可实现时长，说明实际缺口；不循环添加形容词、镜头或特效以抬高自评分。

## 4. 实际生成验证

仅在用户要求并具备生成条件时评估成片。记录模型/入口版本、参数、素材和提示词版本；看真实画面、声音、动作与连续性，不用文本评分代替视频。

比较改动时以完整故事为主，在相同模型/入口、素材、参数和生成次数下观察故事覆盖与因果、主体稳定、表演、动作可读性、镜头叙事、审美、声音和连续性，结合盲评或用户偏好。简单观察、编辑和格式探针用于补充边界验证。

术语表达可单独比较“术语”“术语加具体制作控制”“再加定义释义”。对重复释义是否有用的结论需要成片证据；这不限制首稿主动设计所需细节。短或长本身都不构成优劣证据。
