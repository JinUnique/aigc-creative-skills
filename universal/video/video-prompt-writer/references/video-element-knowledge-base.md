# 专业知识与描述密度

本文件帮助把专业知识转成有贡献的制作选择。写作 Agent 已理解的常用影视词汇无需重复教学；最终视频提示词仍需充分表达所选的影像、表演和声音细节。这里保留选择条件、技法边界、消歧与任务绑定，不把少写细节当作目标。

## 术语何时展开

| 当前情况 | 写法 | 检查问题 |
|---|---|---|
| 含义稳定、对象已明确 | 直接写专业名词 | 再加一句是否只是在解释同一术语？ |
| 故事已定，制作空间未锁定 | 主动选择美术、表演、镜头和声音，并写足具体控制 | 哪种选择能让故事、情绪与审美更好地呈现？ |
| 多个主体或空间层，作用目标不明 | 名词 + 目标/关系 | 焦点、跟随对象、受光对象是哪一个？ |
| 结果依赖路径、顺序或时点 | 名词 + 必要执行条件 | 何时开始、沿哪里、到哪里停止？ |
| 罕见词、多义词、跨语言混淆 | 简短说明预期结果，必要时保留原词 | 额外说明是否消除了具体歧义？ |
| 当前视频模型已经执行失败 | 针对失败补一个控制点或简化指令，再观察 | 修复的是哪项实际偏差？ |
| 只是强调气质、情绪或创作自由 | 保留有效的抽象意图 | 具体化是否反而锁死用户希望保留的自由度？ |

文本模型理解专业词与视频模型稳定执行该词是两项能力。定义释义不必机械展开；所选制作方案需要的具体细节可以在首稿充分表达，不需要先有失败证据。收到反馈后针对实际偏差改进，不把局部修复升级为所有任务的新模板。

## 容易混淆的技法

| 决策 | 需要明确的边界 |
|---|---|
| 推轨 dolly / 变焦 zoom | 推轨改变摄影机位置及视差；固定机位变焦改变取景范围。需要显著空间关系变化时，不以两者互换 |
| 广角/长焦与透视 | 透视关系取决于拍摄位置；同等主体构图下，长焦通常伴随更远机位而呈压缩感。同一机位换焦段不凭空改变透视 |
| 浅景深 / 深焦 | 当前注意对象明确时可直接使用。多个深度层需要同时可读时选择深焦，不能同一时刻又要求它们全部虚化 |
| 移焦 / 相机移动 | 移焦可以在固定机位发生；需要表达所选注意力交接时写起止对象与节点，不把移焦写成空间移动 |
| 固定机位 / 冻结画面 | 固定的是摄影机。观察片段可以保留画内运动，也可以有意维持稳定状态，不强制补微动作 |
| 曝光 / 光源变化 | 自动曝光变化与场景实际灯光改变不同；涉及材质反射、阴影或连续性时说明控制的是哪一项 |
| 慢动作 / 音频时间 | 视觉时间、音高和音频时长可分别设计；慢动作不自动要求全部声音变慢 |
| 叙事内声 / 声源是否入画 | diegetic 指属于故事空间，声源可以在镜头外；旁白可不属于该空间，不自动经过画中墙体的遮挡与混响 |
| 物件声音 / 空间尾音 | 接触瞬态、物件自身共振和房间混响分别决定声音；硬材质不等于衰减必短 |
| 相对静默 / 纯静音 | 前者可保留环境或呼吸，后者不生成任何声层，按用户音频意图区分 |
| 连续叙事 / 蒙太奇 | 完整动作关注空间与因果接续；用户明确要主题/节奏蒙太奇时可按该关联组织，不额外制造线性剧情 |

## 风格知识的使用

风格词是入口，创作知识帮助选择适合本次目标的组合。读取用户提供的风格指南或项目 reference 时，区分：

- **审美不变量**：用户认可的构图、比例、材质、光色关系或节奏原则。
- **可变内容**：主体、地点、时代、物件和事件；只有被本次 brief 锁定才必须继承。
- **适用条件**：特定效果何时有效，与哪些需求冲突，何时应省略。
- **示例职责**：说明一种选择及其结果；不把示例全部内容加入后续请求。

同一风格可以使用不同场景和技法。跨主体迁移时先保留用户重视的关系，再调整不适用的默认值。无具体用户取向时不自动加载一个垂类风格包，也不将所有作品导向同一种光色或奇观。
