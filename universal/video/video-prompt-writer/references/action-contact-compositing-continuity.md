# 动作、接触、合成与物理连续性方法库

本文件用于单片段视频提示词中的动作编排、接触反馈、合成可信度和物理连续性设计。它只提供通用方法、检查问题和中性占位槽，不提供固定人物、固定场景、固定武器、固定招式、固定剧情桥段或垂类样本。

核心目标是让复杂动作和视效从“看起来发生了”变成“在同一个可见世界里真实发生”：动作有准备与结果，接触有受力与反应，特效与实拍空间有遮挡、光影、深度和残留，多个分镜之间的状态能接上。

---

## 一、适用范围

当提示词包含以下任一情况时，查本文件：

- 主体有快速移动、追逐、躲避、抓取、推拉、冲撞、坠落、托举、旋转、挣脱或群体调度。
- 主体与主体、主体与物件、主体与环境、视效与实体之间发生接触。
- 视效需要和场景合成在一起，而不是漂浮在画面表面。
- 多个分镜连续呈现同一动作、同一物件状态、同一损坏状态、同一光线或同一空间方向。
- 生成结果常见问题是动作假、接触虚、遮挡错、光影不贴、主体穿模、冲击无反应、视效像贴片。

本文件补足 `vfx-design-dimensions.md` 的“接触、合成、连续性”层。前者回答视效从哪来、往哪去、留下什么；本文件回答动作如何被看清、力如何传递、视效如何嵌入空间、状态如何跨镜延续。

## 二、动作可读性：让观众看懂力从哪里来

动作不是动作名，而是一组可读阶段。复杂动作至少要写出其中多数关键阶段。

| 阶段 | 提示词要写什么 | 不合格写法 |
|---|---|---|
| 准备 | 重心、视线、手部/脚步/身体预备、距离变化 | 直接写“突然动作” |
| 发起 | 起点、方向、速度、身体部位或物件如何启动 | 只写“冲过去 / 打过去” |
| 路径 | 运动路线、弧线、阻力、绕行、穿越空间层级 | 没有方向和空间关系 |
| 接触 | 接触点、接触面、先后顺序、是否被遮挡 | “撞到”但不知道撞哪里 |
| 受力 | 力的方向、强弱、偏转、回弹、拖拽、压迫 | 没有反应，像无重量 |
| 反应 | 对方身体、物件、衣料、表面、环境如何变化 | 事件结束后画面不变 |
| 恢复 | 停顿、失衡、重心调整、残留动作、下一步意图 | 动作切走，状态断裂 |

### 2.1 动作意图槽位

写动作前先给动作一个清楚意图：

```text
动作意图：主体为了<接近/远离/阻挡/保护/夺取/逃脱/观察/隐藏/控制/恢复平衡>，从<起点>沿<路径>向<目标点>移动。
```

动作意图不是剧情解释，而是决定身体路径、镜头跟随和接触结果的物理目标。

### 2.2 身体力学槽位

用于人、动物、机械、物体或抽象主体的运动，不限定题材：

```text
身体/主体力学：<重心位置>先<转移/下沉/抬高/偏移>，<主要部位或结构>带动<次级部位或外部物件>，形成<方向/速度/幅度>的运动。
```

非人主体要按自身结构写，不套人类动作模板：

- 机械主体：关节、轮组、履带、液压杆、转轴、外壳震动。
- 软体主体：收缩、伸展、波动、黏附、回弹、拖曳痕迹。
- 流体主体：流向、涡旋、边缘破碎、溅射、附着、蒸发。
- 光/能量主体：亮度变化、边界稳定度、频率、折射、投影、接触后的介质反应。

## 三、接触链：把碰撞写成可见因果

任何接触事件都至少回答：谁碰到什么、哪里先碰、力往哪里走、被碰对象怎么变、事件后留下什么。

```text
接触链 = 动作来源 → 运动路径 → 接触点/接触面 → 受力方向 → 材质响应 → 主体反应 → 环境/声音/残留
```

### 3.1 接触点类型

| 类型 | 写法重点 |
|---|---|
| 主体接触主体 | 双方接触部位、受力方向、距离变化、表情/重心/呼吸反应 |
| 主体接触物件 | 手、脚、身体或工具与物件的接触面、摩擦、位移、损坏或所有权变化 |
| 主体接触环境 | 地面、墙面、门框、水面、植被、家具、结构面出现压痕、震动、碎屑、反光或位移 |
| 物件接触物件 | 两个材质的硬度差、碰撞方向、弹跳、破裂、滑动、卡住或滚落 |
| 视效接触主体 | 光影、气流、热量、冲击、牵引、包裹、压迫或状态转换作用到身体、服饰、道具 |
| 视效接触环境 | 空气、尘雾、水面、墙面、地面、玻璃、金属、织物等出现对应扰动 |

### 3.2 受力方向菜单

- 推开：受力对象沿远离来源方向移动，接触面产生压缩或滑移。
- 拉回：受力对象朝来源方向偏移，连接处紧绷或被拖拽。
- 斜切：受力沿侧向掠过，表面出现擦痕、旋转或偏转。
- 下压：受力向下，地面/支撑物出现压痕、弯曲、震动或沉降。
- 托起：受力向上，主体离开支撑面，衣料/悬挂物出现滞后。
- 包裹：力从多方向收拢，边缘、褶皱、粒子或流体贴住目标外形。
- 穿透：路径穿过对象，必须写入口、出口、材质变化和残留边缘。
- 反弹：受力后方向改变，回弹速度、二次碰撞或停顿要可见。

### 3.3 材质响应菜单

- 硬质：裂纹、碎屑、火花、凹痕、反弹、清脆声。
- 软质：压陷、拉伸、褶皱、回弹、闷响。
- 液体：波纹、飞溅、拖尾、附着、滴落、折射。
- 粉尘/颗粒：扬起、扩散、沉降、附着、被气流带偏。
- 织物/毛发：抖动、贴附、翻卷、拉扯、滞后摆动。
- 金属/玻璃：反光变化、变形、裂纹、碎裂、尖锐余波。
- 光/烟/雾：亮度衰减、边缘破碎、被遮挡、穿过介质、留下残光或烟带。

## 四、合成可信度：让视效嵌进空间

视效不是单独一层图案。它要和前景、中景、背景、光源、焦点、遮挡和材质同处一个摄影空间。

### 4.1 深度与遮挡

写视效或快速动作时，至少处理一个深度关系：

- 前景遮挡：近处物件、身体局部、烟雾、门框、玻璃、植被、人群是否部分遮住事件。
- 中景行动面：主体动作和接触点发生在哪个平面。
- 背景响应：远处光线、尘雾、墙面、水面或人群是否被事件影响。
- 穿越层级：主体或视效是否从前景穿到中景、从背景冲到前景，遮挡顺序是否变化。
- 焦点层级：焦点停在接触点、主体反应、路径前端还是余波残留。

不需要写技术术语，但必须写清“谁在前、谁在后、谁遮住谁、焦点在哪里”。

### 4.2 光影匹配

视效和场景要共享光线规则：

```text
光影匹配：<视效/动作>产生或遮挡<光源/阴影/反射>，使<主体/物件/地面/空气>出现<亮度/色温/轮廓光/接触阴影/反光/阴影移动>变化。
```

检查点：

- 光源方向是否一致，不同分镜是否突然反向。
- 视效发光时，附近表面、衣料、皮肤、金属、水面或尘雾是否被染色。
- 大体积物体或主体接近地面/墙面时，是否有接触阴影或遮光关系。
- 烟雾、尘埃、水汽、雨雪等介质是否让光束、亮边或阴影可见。
- 反射材质是否出现环境和事件的相应变化。

### 4.3 运动模糊与速度感

速度感不能只写“很快”。要让画面知道速度如何被记录：

- 快速主体：边缘拖影、背景相对位移、衣料/毛发/附属物滞后。
- 镜头跟随：主体相对清楚，背景产生方向性运动模糊。
- 冲击瞬间：接触点短暂停顿，随后碎屑、衣料、气流或表面反应扩散。
- 慢动作：不只放慢主体，还要放慢尘埃、液滴、布料、表情和声音衰减。
- 静止压迫：主体不动时，空气、光线、微尘、手指、呼吸或远景运动承载紧张感。

## 五、物理连续性台账

多个分镜连续呈现同一事件时，提示词要维持状态，而不是每镜重置世界。

### 5.1 连续性字段

| 字段 | 要保持或推进什么 |
|---|---|
| 空间方向 | 主体朝向、屏幕方向、移动路线、轴线、地标位置 |
| 主体状态 | 姿态、重心、速度、表情、呼吸、伤损、衣料/毛发状态 |
| 物件状态 | 所有权、位置、损坏、开启/关闭、湿度、温度、发光、残留 |
| 接触状态 | 接触是否持续、断开、滑移、被遮挡、转移到另一对象 |
| 视效状态 | 形状、亮度、边界、残光、烟尘、水汽、碎片、光源影响 |
| 光线状态 | 光源方向、强度、色温、闪烁、阴影位置、反射关系 |
| 声音状态 | 环境底噪、冲击余音、呼吸、材质摩擦、远近变化 |
| 情绪状态 | 上一镜造成的身体反应和关系变化是否延续 |

### 5.2 跨镜接续句式

用于提示词内部的中性占位句：

```text
上一镜留下的<物件/视效/尘雾/光线/身体状态>继续存在，<主体/镜头/环境>从这个状态接上，变化为<新状态>。
```

```text
镜头不重置空间方向，保持<主体A/主体B/关键物件>的相对位置，新的动作从<上一接触点/上一视线方向/上一声音来源>延续。
```

这些句式是结构占位，不是固定剧情。使用时替换为当前任务的具体主体、位置和状态。

## 六、多主体与环境反应层

复杂事件要分主次。不要让所有主体同时做同等强度的动作。

### 6.1 反应层级

| 层级 | 写什么 |
|---|---|
| 主动作主体 | 发起动作的目标、路径、速度、接触点和情绪证据 |
| 被作用主体 | 受力方向、身体/结构反应、表情/声音/状态变化 |
| 旁观或次级主体 | 视线、后退、停顿、遮挡、保护、误判或延迟反应 |
| 近处环境 | 地面、空气、道具、衣料、尘雾、光影如何同步变化 |
| 远处环境 | 背景声、远景光线、结构震动、人群或自然介质如何滞后响应 |

### 6.2 反应延迟

真实反应常常不是同一帧完成：

- 接触瞬间：接触点和声音先出现。
- 极短延迟：身体、衣料、道具或尘雾跟着反应。
- 后续余波：背景、远处介质、光线、呼吸或情绪状态慢半拍变化。

写延迟能让事件更有重量，也能避免所有元素同一时间炸开导致画面假。

## 七、镜头承载与可生成性负载

复杂动作、复杂视效和复杂多主体不要全部塞进一个短镜头。先决定观众必须看清什么，再控制负载。

### 7.1 负载判断

一个分镜里同时出现下列项目超过 3 项，就应拆分或降低复杂度：

- 多个主要主体同时高速移动。
- 大体积视效生成、扩散、碰撞和余波同时发生。
- 镜头大幅甩动、快速推拉、环绕或频繁变焦。
- 多个空间层级同时发生关键动作。
- 长对白、画外音、环境声和冲击声同时承载信息。
- 关键物件所有权、位置或状态发生变化。
- 情绪转折需要观众读表情或细微身体反应。

### 7.2 拆分策略

- 先看清动作来源，再看接触，再看反应与余波。
- 大体积视效先给生成机制，再给接触范围，再给环境残留。
- 多主体事件先锁主动作主体，再用反应镜头或同镜次级动作补其他主体。
- 镜头运动服务注意力路径；如果接触点很重要，就不要用过强甩镜遮掉它。
- 慢动作只用于关键接触、失衡、爆发前后或情绪落点，不用于全部动作。

## 八、反模式

出现以下情况，应判为动作/合成层不合格：

- 只写动作名称，没有准备、路径、接触、受力和反应。
- 主体与物件“碰到”但没有接触点、材质响应、声音或余波。
- 视效漂在画面表面，没有遮挡、接触阴影、反射、交互光或介质扰动。
- 大冲击后主体、衣料、地面、空气、道具和背景都没有变化。
- 多个分镜之间物件位置、主体方向、损坏状态、光线方向或视效残留突然重置。
- 镜头运动比事件本身更强，遮掉关键接触点或让空间方向不可读。
- 所有角色和环境同一时间同强度反应，没有主次、延迟和余波。
- 用固定招式名、设定名、题材词或抽象能量词替代可见物理过程。

## 九、内部控制槽位与渲染

需要动作、接触或合成加强时，先用以下槽位做内部校验，再把适用信息写进对应时间片字段。不涉及人工视效或显著物理变化时自然省略，不输出“无视效”占位：

```text
动作路径：<主体>从<起点>沿<方向/弧线/层级>移动，<重心/部位/结构>先<准备动作>，随后<发起动作>。
接触反馈：<接触点/接触面>先碰到<对象>，力沿<方向>传递，造成<材质响应/位移/形变/破裂/滑移>。
合成关系：<适用的可见变化/主体/物件>位于<前景/中景/背景>，被<遮挡物/介质/光线/焦点>部分遮挡或揭示，并在<接触面/空气/反射面>留下<与当前事件相符的响应或残留>。
连续性：上一镜的<状态>延续到本镜，<主体/物件/视效/声音>从<旧状态>变化到<新状态>。
反应层：<被作用主体/次级主体/环境>分别出现<身体反应/视线反应/声音反应/材质反应/延迟余波>。
```

## 十、自检

交付前对动作和合成层问 10 个问题：

1. 动作有没有准备、路径、接触、反应和恢复？
2. 接触点是否具体到部位、物件面或空间面？
3. 力的方向和强弱是否能从画面看出来？
4. 被作用对象是否有材质响应、位移、形变、声音或残留？
5. 视效是否和前景、中景、背景有遮挡或深度关系？
6. 发光、阴影、反射、尘雾、水汽或空气介质是否响应事件？
7. 多主体反应是否有主次和延迟，而不是同一时间同强度？
8. 跨镜的主体方向、物件状态、损坏状态、光线和视效残留是否接得上？
9. 镜头运动是否帮助看清关键接触点，而不是遮掉它？
10. 当前分镜负载是否过高，是否需要拆成来源、接触、反应、余波几个节拍？

任一问题答不清，就回到接触链、合成可信度或连续性台账补齐。
