# 视频提示词表达结构

内部规划解决制作选择，正文充分表达选定结果。提示词长短由故事、视听设计和视频模型控制需要决定，没有短文目标。主 skill 定义交付范围、字符上限和默认约束；本文件负责如何把信息组织成可用的提示词。

## 选择表达形态

| 任务 | 正文形态 | 必要内容 |
|---|---|---|
| 单一观察、简单动作或气氛片段 | 一个自然段 | 主体/参考、核心变化、选定影像语言、必要限制 |
| 局部视频编辑 | 一段编辑指令 | 编辑对象、要改变什么、时间/区域范围、要保留什么 |
| 多阶段行动或多镜头 | 全局基线 + 按阶段/时间组织的内容 | 关键事件顺序、摄影机行为、状态变化，适用的声音节点 |
| 连续 prompt pack | 每段独立正文 + 外部交接清单 | 各段独立锚点、本地时序、可接续状态 |
| 明确的下游模板 | 保留调用方指定格式 | 所有必需字段；不适用字段按该接口规则表达 |

字段的存在由交付需要决定，字段中的细节由本次控制需要决定。两者不能推出“每个主体都要完整五官服饰设定”“每镜必须有情绪变化”或“每条必须有 VFX”。

## 信息安排

1. **主体与空间基线**：只写主体辨识、动作、空间和连续性所需信息。没有人物时直接描述物体或环境；仅作尺度参照的人物不需要面部特写级设定。素材已承担外观时使用其句柄与职责，正文补变化和未覆盖约束。
2. **影像意图与美术**：主动选择相互支持的风格、摄影、色彩、光线与材质关系，让场景和人物具备适合故事的形象。常用专业词无需附定义；决定具体外观和观看感受的光源位置、影调、轮廓、质感或空间细节可充分表达，不必等待连续性问题或生成失败。参考已解决的属性不重复重建。
3. **事件、表演与摄影**：安排事件如何被看见，关键表情和动作如何让观众读出人物状态。选择适合的视点、景别、焦点和镜头衔接，给准备、关键接触、反应和落点合理时间；不把全景固定记录当作所有故事的默认解法，也不把多镜头当作质量指标。用户要连续观察时，稳定状态也是有效内容。
4. **声音与约束**：为适用任务设计环境、动作、人物声音及其层次、同步与余波，让声音参与空间、节奏和情绪表达。无声任务明确全程静音即可；未设计人工 VFX 时无需占位。禁止项针对用户约束或实际失败风险，不展开通用负面词清单。

故事完整只意味着情节已确定，不意味着制作设计已完成。先形成能贡献观看效果的方案，再决定信息组织形式；没有标签配额，也没有细节数量上限目标。

## 结构化正文

内容复杂或调用方需要稳定标题时，可采用以下骨架。花括号说明字段用途，不是要求补齐的成片内容；实际交付删除空标题、说明和未使用字段。

```text
【基础设定】
{主体、参考职责、空间和必要起始状态}

【氛围与画质】
{选定的风格、摄影、光色；与基线相同的信息不重复}

【画面内容】
时间段：{仅在需要时间码时填写本地范围}
景别/镜头：{当前视点及需要看清的内容}
运镜：{摄影机行为；可与景别合写，固定基线无需逐段重述}
画面内容：{主体行动、关系和状态变化}
视效/VFX：{仅在效果需要单独控制时出现}
声音/对白：{仅在有声层或特定同步要求时出现}
情绪转折：{仅在转折需要单独说明时出现}

【声音约束】
{适用的生成/保留/后期归属与音频限制}

【画面约束】
{当前任务的必要限制}
```

已明确要求上述五个标题、七个时间片标签的调用方仍可使用它们，并按约定处理不适用项。格式中立不会取消用户指定的分镜时间、角色台词、镜头数量或约束。调用方没有要求字段时，不主动增加这套标签。

## 中性表达短例

这些片段说明表达方法，不提供可继承的人物、题材或风格组合。

| 条件 | 可交付表达片段 | 关键选择 |
|---|---|---|
| 一个明确焦点，用户已指定浅景深 | `固定机位，浅景深。` | 使用术语本身，不重讲背景虚化定义 |
| 同镜两个焦点，需要在特定节点交接 | `主体 A 停下后移焦至主体 B。` | 增加目标与触发，保留镜内连续性 |
| 参考视频仅修改一项属性 | `仅修改 @视频1 中指定主体的颜色，其余内容与原声保持不变。` | 编辑范围直接表达，不重建全片设计 |
| 声源跨剪点 | `该声源延续至下一镜，待主体反应后收住。` | 写声音的起止职责，无需解释声音桥术语 |

素材名称和主体代称在实际交付中必须来自当前任务；不得把例中的 `@视频1` 当作真实已上传资产。

## 压缩与补充

1. 删除诊断、备选方案、空标签、未使用的模板说明。
2. 合并同一段的重复基线、同义修饰和专业术语定义。
3. 删除无助于本次观看效果的装饰细节和越过锁定边界的新情节；保留有贡献的制作创作。
4. 用明确术语和关系句替代绕行描述；素材已完整表达的部分仅指认其职责。
5. 复核故事事实、执行范围、场景美术、表演、镜头组织、声音、节奏与连续性。为表现目标补足需要的设计和执行信息，不按细节数量或字符目标补写或删减。

常用术语的定义与当前作品的具体设计不是同一种信息。对写作 Agent 显而易见的关系，仍可能是视频模型需要的明确控制；不能仅因 Agent 已理解就从最终提示词删除。

独立生成的下一段不自动继承上一段上下文。只有确认素材/工具确实承载该状态时才能省略对应重述；必要跨段锚点不是段内冗余。
