# 视频提示词表达结构

内部规划解决制作选择，正文充分表达选定结果。提示词长短由故事、视听设计和视频模型控制需要决定，没有短文目标。主 skill 定义交付范围、字符上限和默认约束；本文件负责正文形态、字段职责与渲染。

## 选择表达形态

先遵从用户或下游明确指定的格式；未指定时按任务选择：

| 任务 | 默认正文形态 | 必要内容 |
|---|---|---|
| 局部视频编辑 | 一段编辑指令 | 编辑对象、要改变什么、时间/区域范围、要保留什么 |
| 单镜头且无复杂时序/同步关系的简单观察、动作或气氛片段 | 一个自然段 | 主体/参考、核心变化、选定影像语言、必要限制 |
| 完整故事、多阶段行动或多镜头 | 下述五区块、七字段结构 | 全局基线、事件时序、镜头关系、适用的声画设计与状态衔接 |
| 连续 prompt pack | 各段独立结构化正文 + 外部交接清单 | 各段完整基线、本地时序、可接续状态 |

单镜头不等于简单任务：有多个重要事件、反应或同步关系的长镜头使用结构化正文。多阶段或多镜头的气氛、观察与实验影像同样不适用自然段例外。用户给出完整故事时按故事处理，不以时长短或人物少为由降为简单观察。多个时间片也不意味着必须切镜。

结构化默认保留五个标题和各时间片的七个标签及其顺序；字段内容由本次制作需要决定。无人工视效可写 `无人工视效`，无新增声层可写 `延续全局声音设计`，稳定状态可写清保持的结果。不填空白占位，不为标签制造角色、对白、特效或情绪变化。

## 全局与局部分工

| 区块 | 职责 |
|---|---|
| `【基础设定】` | 主体辨识、空间关系、参考素材职责和必要初始状态。人物外观与场景美术按观看效果设计，不要求所有人物都有完整五官服饰清单；素材已承担的外观只指认其职责 |
| `【氛围与画质】` | 全片选定的风格、摄影质感、光色、材质和氛围基线。专业词可直接使用；有贡献的具体设计充分表达，不用画质形容词堆叠替代选择 |
| `【分镜与时间轴】` | 按时间片组织事件、表演、摄影、视效与声音，表达先后、并行、触发和结果 |
| `【声音设计与约束】` | 持续环境声、声音身份与空间、混音基线、生成/参考/后期归属和音频限制。局部台词与事件音放在相应时间片 |
| `【画面约束】` | 当前任务的必要限制，不重抄基础设定、风格和动作。默认值按主 skill，用户约束优先 |

同一提示词的持续基线只定义一次，时间片写当前动作和局部变化。共享基线可以被明确的节点改变，不把初始状态误锁为全片不变。独立生成的下一段不自动继承上下文，必要的跨段锚点仍须重述。

## 结构化正文

花括号说明字段用途，实际交付替换为本任务内容并删除说明。

```text
【基础设定】
{主体、参考职责、空间和必要起始状态}

【氛围与画质】
{选定的风格、摄影、光色和材质基线}

【分镜与时间轴】
时间段：{本地范围或明确阶段；镜头标识及切镜/镜内延续关系}
景别/镜头：{当前观看位置、构图、空间层次与需要看清的对象}
运镜：{摄影机运动、焦点交接及其触发与落点}
画面内容：{主体动作、表演、空间关系与可见因果}
视效/VFX：{适用效果的触发、发展、交互与落点；或无人工视效}
声音/对白：{对白归属、原文、语气与交付节点；事件音及其时序；或全局声层的延续}
状态与衔接：{需要保持或传递的可观察结果、情绪表现及镜头/片尾接点}

【声音设计与约束】
{全局声音方案、声层归属与限制；纯静音可明确全程无声}

【画面约束】
{当前任务的必要限制}
```

用户/下游指定旧版 `【画面内容】`、`【声音约束】`、`情绪转折` 或其他格式时，保留其名称、顺序与字段职责；将必要动作状态和衔接放入适合的既有字段，不额外套一层默认模板。

## 时间片内的关系

1. **镜头与时间片**：在时间段中说明镜头归属；边界按设计写切镜或同镜延续。景别字段负责观看位置与构图，运镜字段负责摄影机和焦点的变化。同镜沿用的构图可简写，发生变化的对象、方向和节点仍须明确。
2. **动作与表演**：画面内容围绕事件描述可见过程，关键路径、接触、反应和落点按任务需要展开；表情、视线、呼吸和身体变化与动作发生关系。不逐片重复服装、光线或场景清单，不设细节数量配额。
3. **视效与作用**：需要效果时写清从何时/何处出现、如何发展、怎样影响当前画面及留下什么状态。普通自然变化可融入动作句，不因保留 VFX 标签而追加无关光影或介质。适用机制按 [VFX](vfx-design-dimensions.md) 设计。
4. **声音与对白**：复杂声层可在同一字段内分行列对白、音效或环境变化。对白绑定说话者、原文、交付节点与表演；音效绑定声源、触发与余音，需要时确定听觉前景。持续底层不逐片重抄。对白可跨画面剪点延续，交付区间与生成段收尾按 [对白计时](dialogue-pace-and-voiceover.md) 校验。
5. **共同事件节点**：动作、效果、声音和摄影使用同一事件作参照，明确事件前、发生时、之后或有意错开的关系。字段顺序不是发生顺序；并行事件不写成轮流执行。可用自然触发句，不为每个微动作添加精确时间码，也不把所有声画关系强制同步。
6. **状态与衔接**：情绪可保持、积累或变化，并有适用的表演/声线依据。片尾状态也可落在位置、物件、关系或信息显露，不强制情绪转折。只补影响后续的保持、变化或接点，不复述已明确的整段动作；末片按作品结尾收束，不默认要求后续片段。

故事完整只意味着情节已确定，不意味着制作设计已完成。结构承载选定的视听方案；需要的动作、表演、特效、对白和声音细节不能因已有标签而省略。

## 中性表达短例

这些片段说明表达方法，不提供可继承的人物、题材或风格组合。

| 条件 | 可交付表达片段 | 关键选择 |
|---|---|---|
| 一个明确焦点，用户已指定浅景深 | `固定机位，浅景深。` | 使用术语本身，不重讲背景虚化定义 |
| 同镜两个焦点，需要在特定节点交接 | `主体 A 停下后移焦至主体 B。` | 增加目标与触发，保留镜内连续性 |
| 参考视频仅修改一项属性 | `仅修改 @视频1 中指定主体的颜色，其余内容与原声保持不变。` | 编辑范围直接表达，不重建全片设计 |
| 声源跨剪点 | `该声源延续至下一镜，待主体反应后收住。` | 写声音的起止职责，无需解释声音桥术语 |

素材名称和主体代称在实际交付中必须来自当前任务；不得把例中的 `@视频1` 当作真实已上传资产。

## 压缩与补充

1. 删除诊断、备选方案和未替换的模板说明；默认结构或调用方要求的标签保留，不适用项简短表达。
2. 合并同一段的重复基线、同义修饰和专业术语定义。
3. 删除无助于本次观看效果的装饰细节和越过锁定边界的新情节；保留有贡献的制作创作。
4. 用明确术语和关系句替代绕行描述；素材已完整表达的部分仅指认其职责。
5. 复核故事事实、执行范围、场景美术、表演、镜头组织、声音、节奏与连续性。为表现目标补足需要的设计和执行信息，不按细节数量或字符目标补写或删减。

常用术语的定义与当前作品的具体设计不是同一种信息。对写作 Agent 显而易见的关系，仍可能是视频模型需要的明确控制；不能仅因 Agent 已理解就从最终提示词删除。
